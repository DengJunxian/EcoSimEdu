# 双向拍卖模型 v1

案例身份为学术实验。引文用于解释 Smith 实验的制度与背景。案例中的 20 个角色、初始数据、策略和轨迹属于教学模拟。当前市场只交易一种不可分商品，买卖双方各 10 人，单位数量 1–3，B01 由学生指定一件限价单。经济单位为代币和件，时间单位为事件序号。

用原有 Python OrderBook 撮合。市场规则为整数报价、实验时钟、价格优先与同价时间优先、在簿价成交、无做空、无 A 股会话和税费。固定一侧每人最多一张一件有效单，以报价加费用预留可用现金或以一件可用库存约束卖单。自动角色按预定顺序撤销剩余单、提交新单。前一成交价影响后续自动报价，时间推进时私人限价与参考价之间的差距缩小。自动买单报价上限为边际价值减费用，卖单下限为边际成本加费用。经济结果由撮合与账务决定。

基准、买方价值 +12、双边每件收费 6 三组共用同一根角色配置、随机顺序与报价噪声和学生报价。需求干预改变买方边际价值，费用干预改变价格约束与记账。随机策略、订单时序、有限回合和整数价格均影响结果。单条轨迹支持当前设定的机制分析。费用归平台账户。含平台收入的总剩余为每笔成交的价值减成本总和。最大剩余是排序配对的无费用技术上界。无正潜在剩余时效率留空。竞争价格区间在离散竞争配对对应的供需切点计算，不向报价策略提供。

每个事件绑定订单 ID、角色与变更。每个快照与结束指标可由事件检查。教学文本为本项目编写，引用仅登记支持范围。纸面题中的数值用于算式说明。
