# 居住隔离模型 v1

学术来源为 Schelling（1971）。运行使用 20×20 的抽象地图，各 170 名 A、B 居民和 60 个空位。地图是种子驱动的教学初态。A001 的开局动作可在同一空位保持或搬迁。空位按固定种子挑出，三组实验保持初态与学生动作一致。

邻域为网格上不跨边界的八邻域。令 c 为同类邻居数，n 为已占邻居数，满足 n=0 或 100c≥τn 时居民满意。自动更新先按局部种子随机化了访问顺序，再让每位不满意居民迁到排在前面的可接受空位。评估目的地时排除居民自己原先占据的位置。找不到位置时保留原坐标。每次迁居立即变更原址与新址邻居的邻接组合。更换一个阈值即可形成 0%、30% 和 50% 的配对实验。在最多八轮顺序更新内检查全员满意或无可迁移，达到上限时展示尚未稳定。

满意率以全部居民为分母。同类邻接率以已占位置间的无向八邻接边为分母，孤立居民不增加该分母。示例中，若 A 位于左上角，周围有 1 个 A、2 个 B，则局部比例是 1/3。在 30% 条件下满意，在 50% 下不满意。在左上角的这 3 条邻接边中，同类边只有 1 条。模型中的满意变量衡量阈值是否达到。现实城市的房价、信贷、规划与历史制度需要独立资料。
