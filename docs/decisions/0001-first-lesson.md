# ADR 0001 · 独立学生端与双向拍卖适配

接受。React/TypeScript 学生端在 Vite 构建后由 FastAPI 本地同源提供。旧入口 `streamlit run app.py` 保留。前端通过同一契约查看和比较运行，离线资产均在当前仓库。选择本地系统字体和矢量数据图以减少下载量。

复用 Demo 的 Python LIMIT 撮合。旧撮合存储和市场默认税费通过独立市场规则配置。固定每次一件，账户和费用守恒由教学适配器管理。一次课内执行可同步算完，SQLite 事务原子提交状态和结果。播放支持停顿、跳转与倍速，执行暂停与运行中取消由更长任务的 Provider 实现。一个显式 `request_id` 允许重试，取消限于 created。

规则计算与预设回放共用事件模型。规则结果可以复现，回放只装载已验证的固定种子与报价，并保留数据身份。Live 尚不可用，调用请求显式返回 503。课程配置、请求和结果契约分开。其余案例的领域插件与运行队列保留为后续范围。

回滚教学层只需停用学生端入口，旧演示可单独启动。已移除的默认凭证继续由环境变量配置。
