# EM05 公共物品与供应链反馈

公共物品课显示实际人均投入，以本轮公开贡献人数为分母。个人净收益与全组净收益继续从真实结算核对。反馈段可返回上一轮结算，比较同一参与者的上一轮贡献、被罚扣损与本轮贡献，并区分自动规则和学生计划。

啤酒游戏用一期初末库存、实际到货和实际发货复核库存恒等式。零售实发从累计交付差计算，其他环节使用记录的发货批次。逐层订单放大采用已完成周的订单方差与终端需求方差，零分母和样本不足显示无法计算。原批次来源和按周对照继续使用。

两课在解释阶段可提交分别保存的解释卡，必须引用实际结算或周账本。构建与机制／浏览器套件 18 项通过（13.72s）。本轮未使用真实学生评价。
