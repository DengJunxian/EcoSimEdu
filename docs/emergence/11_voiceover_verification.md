# rc.4 系统旁白补验

## Chrome 158

从已校验的 rc.4 离线包启动独立回环服务和临时 SQLite。测试在原生 Chrome 158.0.8127.36 的临时浏览器配置中进行，网络请求限定为该回环服务。截图只采集 macOS 的旁白字幕窗，且采集前后均核对隔离的 Chrome 进程处于前台。以下结论来自逐张查看的实际字幕。

| 操作 | 系统字幕 | 结果 |
| --- | --- | --- |
| 聚焦证据视角选择框 | 模型观察者，证据视角 | 确认 |
| 聚焦真实搬迁事件的引用按钮 | 引用此搬迁，按钮 | 确认 |
| 用回车从指标表回查事件 0 | 标题级别 3 搬迁与邻域 · 事… | 部分确认，字幕截断了事件编号 |
| 聚焦配对引用按钮 | 引用此初态对照，按钮 | 确认 |
| 用回车保存配对引用 | 已引用初态对照 | 确认 |
| 聚焦解释卡的论断字段 | 我的论断，文本输入区 | 确认 |

在发生截断的步骤中，Chrome 的焦点断言确认落在「搬迁与邻域 · 事件 0」，课堂显示「该点无搬迁记录」。这一断言作为界面证据记录。字幕只支持已捕获的部分。

Chrome 共 5 项确认、1 项部分确认。原始字幕图和逐项 SHA-256 存于本机 `output/playwright/emergence/followup/rc4-voiceover/`。

## 原生 Safari 27.0

从同一份 rc.4 离线包启动独立回环地址与临时 SQLite，重新在课内生成两次规则运行。仅在指定 Safari 测试窗口位于前台时采集系统旁白字幕窗口，逐张检查如下四项。

| 操作 | 系统字幕摘录 |
| --- | --- |
| 用键盘从同类邻接率表聚焦第一行事件按钮 | 事件 0，按钮，同类邻接率（%），表格，2 列，4 行 |
| 在同一按钮按回车反查 | 标题级别 3，搬迁与邻域 · 事件 0 |
| 打开机制解释卡 | 写一张机制解释卡，已展开，摘要 |
| 用键盘进入解释卡第一项 | 我的论断，文本输入区 |

反查后原生 Safari 焦点落在三级标题，完整编号也出现在系统字幕中。对照本轮 API，事件 0 是开场事件，事件 2 是 A094 的真实迁居。把初始布局由 seeded 改为 mixed 后，两次运行在更新轮次 1 分别指向基准事件 74 和分支事件 17。Safari 界面显示「已引用初态对照」。该保存反馈以原生可访问性树核验。

旁白开启约 4 分 8 秒。字幕字号从 22 点临时调为 9 点，随后恢复到 22 点，旁白恢复关闭。临时标签关闭，临时服务结束。四张字幕图、SHA-256、两次运行的结果哈希与事件引用存于本机 `output/playwright/emergence/followup/rc4-safari-voiceover/`。Safari 功能复查另见[浏览器与坐标轴补验](10_browser_verification.md)。

Safari 上的证据视角、搬迁引用、配对引用与保存反馈的系统字幕仍待补采。独立教师盲评、真实课堂学习成效与 Live 提供商仍待验证。
