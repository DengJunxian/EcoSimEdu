## 本轮证据

- 通过 Playwright CLI 从实际本机机制索引进入跨课练习，确认十二课入口、三条推荐顺序和四项自查题。批次使用独立浏览器会话，结束后关闭。
- 使用现有 pytest/Playwright 夹具和临时服务复跑 32 项定向测试，65.39 秒全部通过。覆盖涌现 Trace 与揭示、经济时钟配对、Schelling 显微镜、SVB、合作类和分配类课堂、机制索引和学习活动。测试套件为 `tests/contracts/test_emergence_*.py`、`tests/contracts/test_projection.py`，以及 `tests/e2e/` 中的 `test_emergence_microscope.py`、`test_emergence_index.py`、`test_svb_flagship_domain.py`、`test_cooperation_classroom.py`、`test_allocation_classrooms.py`、`test_education_activities.py`。
- 本轮检查了实现和验收证据，未修改产品代码或课程数据。原生读屏证据范围见[系统旁白补验](11_voiceover_verification.md)。
