# EM02 同一观察点的三个镜头

「涌现显微镜」增加主体状态、互动关系和系统指标镜头。三个镜头沿用课堂的运行、结果摘要、回放事件和经济时钟。事件链接从源引用生成。默认至多显示八条关系，剩余记录可展开，主体保持固定。回放切换时旧响应不会覆盖新的时点或视角。

A001 居民镜头重算这一帧自己的邻域与阈值状态。该镜头的 API 不返回全图指标、其他住户行动或原始观察者链接。模型观察者课堂的网格仍显示在证据区外，沿用既有可复查和导出路径。

通过 `python -m pytest -q tests/contracts/test_emergence_schelling.py tests/e2e/test_emergence_microscope.py` 的 4 项合同和浏览器测试。另检验 TypeScript 和 Vite 构建。角色与观察者是课堂读取视角。多用户认证与评分防作弊未在此阶段验证。
