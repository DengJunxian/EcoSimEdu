# EM01 居住隔离｜涌现显微镜

从 [居住隔离课堂](/learn/schelling_segregation) 开始。记录 30% 条件下的格局预测和理由，进入 A001 的开局行动。学生可留在原地或迁入模型预留空位。原七段课程和预测继续使用原格式。

观察页使用原社区网格和邻居表。展开「涌现显微镜」可选已揭示的搬迁，核对该居民前后坐标和局部比例，固定一位受影响邻居。从「全图指标」曲线或键盘可用的「查看指标数据」反查事件。自动迁居显示阈值模型规则，学生开局动作显示其动作身份。无搬迁及指标未变的观察点也可查看。

基准回放结束后，选择交错或分区布局做成对实验。模型保留学生行动、种子、阈值和生成根。界面显示各自初态摘要与引擎版本。共同时点取每场同轮的记录，结束行比较各自停止时的状态。缺一侧记录时显示无法配对。

提交解释卡须填写论断、局部行动、互动与总体指标、条件、待检验的解释假设，并选择当前运行的一次真实搬迁及一次对照的两侧事件。卡片存入现有浏览器数据库的独立任务记录，可导出 JSON 或 Markdown。核对范围为结构和来源，机制推理供学生自评或教师审阅。

## 实际验收

- `npm --prefix student-web run build` 通过（TypeScript + Vite）。
- 新 Trace 的响应通过 JSON Schema 与实际 Run/事件交叉核验。未来焦点、上限越界和无搬迁都经真实请求测试。
- 修改后针对性测试 22 项通过，涵盖 EM00、EM01、Schelling 域机制与旧七段课堂（45.66s）。
- 390px 与 1440px 的完整 Playwright 用例从原预测、A001 迁居、固定邻居，走到同 Run 的曲线反查，再到同轮次配对与解释提交。断言导出引用的运行、事件、邻居 ID、刷新后的卡片和零外部请求。
- 真实规则运行一例为 A001 从第 11 行第 9 列迁至第 10 行第 16 列，同组邻居由 5/7 变为 3/7，记录中的 14 位邻居受影响。全图同类邻接率 50.33% → 50.14%，满意率 80.00% → 79.71%。结果依赖该次模型输入。
- 视图证据见 `output/playwright/emergence/schelling-microscope-390.png` 与 `schelling-microscope-1440.png`。移动端刻度裁切已经修复并重跑。未做本阶段原生读屏或真实学生成效检验。
- 构建成品与源码固定后重新运行全量合约、机制和浏览器测试，438 项通过（293.73s）。第一次全量试跑中途构建了修正后的 SVG，两个在测试开始时加载的坐标断言仍指向旧图，固定快照复跑解决该环境问题。
