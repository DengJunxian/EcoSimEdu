# EM07 分层推理与跨课迁移

六门核心课各增加一道查证次序题、一道开放迁移题，练习沿旧阶段路径可选进入。已完成的旧阶段可用「继续涌现练习」进入新增任务。既有题目的 ID、判据、答案和作答保留。

次序题使用原离线评估器，保留首次无帮助、已看提示或例题、重答的暴露分类。迁移题审核填写结构，反馈提供可检验的口径。开放解释的经济学正确性留给学生自评和教师按主体、关系、指标、边界四维审阅。运行证据须从真实课堂引用。

跨课练习连接空间邻域与序贯决策、库存积压与银行待付、双向拍卖与柠檬市场。无虚构运行数据导入成绩。构建、12 门课程包校验、12 项实际合同与浏览器测试通过（33.21s）。

EM09 复查增加解释卡的引用用途及结构提示标记。提交者为每条来源标明其支持的陈述类型。所选引用经过本地运行验证，记录不代表开放解释已经过经济学评分。
