## 学生和教师入口

| 路径 | 可操作的结果 |
| --- | --- |
| Schelling 显微镜 | 用曲线两端或键盘输入选择起点和终点，列出区间 `(起点, 终点]` 内真实搬迁，逐条跳到同 Run 的前后邻域。引导态只允许当前已揭示范围，主动复盘可使用完整轨迹。等端点或无搬迁返回空结果。固定受影响住户可提交一次反查核对。 |
| SVB → 闪电崩盘 | 从跨课练习启动两场独立的规则实验，分别引用实付导致的现金减少和成交或撤单导致的买方深度减少。作答保存四个解释字段、时间、帮助暴露、两次 Run 标识、结果摘要、引擎版本及事件编号。 |
| 教师复核 | 同一课堂服务的另一浏览器可导入作答 JSON，分别回查两条来源，并按主体、互动、指标、边界给 0–2 分，填写结论与评语。复核追加保存，可导出再交还学生。来源无法核对时禁止评分。文件导入的帮助状态保留其记录身份。 |
| 机制索引 | 十二课均可查规则版本、经济时钟、指标口径及解释边界。六门核心课可以直接打开探究。已有观察进度时定位到原运行，初次使用沿正常活动进入。窄屏探究可在经济世界、主体及系统结果之间切换，共用原运行、游标和固定主体。 |
| 通用证据 | 在原三课基础上为双向拍卖、公共物品和啤酒游戏接入共同三镜头。区间聚合返回前后数值与原事件引用，关系接口遵循同一可见上限。拍卖公共 Trace 保留私有估值和剩余遮罩。Schelling 角色镜头隐藏观察者网格和指标，原观察者回放与导出仍可按原入口访问。 |

| 反事实与核对 | 按同经济时点汇总五个种子的差值范围与样本数，可切换单组原始事件。多变量界面在本课解释阶段完成后开放。比较条件核对保留实际改变的变量、种子、初态和对齐基础的作答及两侧来源。 |

- Schelling 的区间 `(0,1]` 包含 A001 搬迁。局部同组邻居数由 5/7 变为 3/7，14 位邻居受影响。浏览器核对了真实事件编号与回查焦点。
