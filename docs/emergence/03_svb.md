# EM03 硅谷银行教学模型

原银行曲线、提款链、储户选择和两个条件对照继续工作。新增「涌现显微镜 · 银行资金与储户反馈」。从现金下跌点反查实付，在同一帧逐项核对现金、累计申请、实付、队列及权益。消息记录的来源指向真实 `origin_seq`，从未收到消息的时点可用空结果查看。

风险反馈按照储户已观察邻居、上一轮是否急售与轮初待付从实际记录复算。界面标识模型规则。提款还受受保额度、可用余额和先前申请约束。轮末待付另有解释题，可引用实际账表。历史事件身份与教学模拟数据沿用原来源显示。
