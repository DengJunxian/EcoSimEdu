# 新增交互的 Safari 旁白验收

2026-11-18 在 macOS 27.0（26A428）和原生 Safari 27.0 上，用实际 Tab、方向键、回车及浏览器返回键完成三条流程。使用独立的回环地址、临时 SQLite 和该地址的浏览器学习记录。三条来源均为本轮在课内生成的规则运行。作答与评分用于测试。

| 流程 | 实际键盘结果 | macOS 旁白字幕摘录 |
| --- | --- | --- |
| Schelling 区间反查 | 打开区间，改变终点，从 `(0,2]` 的结果跳到事件 2，进邻域表固定 A013 并按回车核对。最终焦点落在结论标题。 | 「起点事件，已揭示事件 0 至 2」「区间内有 1 次搬迁。」「标题级别 3，搬迁与邻域 · 事件 2」「A013，按钮」「标题级别 4，反查成立。所选住户在这次搬迁的受影响邻居中。」 |
| SVB → 闪电崩盘双来源作答 | 用键盘启动两场运行，选择银行事件 4 与闪崩事件 147，填写四个解释字段并提交。保存后焦点停在确认标题，向后可到两条来源链接。 | 「事件 4 · 100 → 68 资金单位」「事件 147 · 282 → 264 股」「标题级别 3，双来源解释已保存，待教师复核。」 |

Schelling 首次按下核对按钮时，按钮在保存中原生禁用，Safari 焦点退回网页。修复后等待保存时保留键盘焦点。如用户仍停在按钮，完成时聚焦结论标题。区间控件同时提供已揭示事件范围和当前结果。等端点 `(0,0]` 已用键盘走查，原生可访问性树显示「这个区间没有搬迁记录。」系统字幕未采到这句的完整文本。双来源作答和教师复核的保存回执也获得明确的键盘焦点。

## 空区间与跨浏览器文件回传补验

另起独立回环课堂，使用原生 Safari 27.0 作为学生端、原生 Chrome 158.0.8127.36 作为教师端。两个浏览器使用各自的学习存储，联到同一个本地运行服务。

| 步骤 | 实机结果及系统字幕 |
| --- | --- |
| Schelling 空区间 | 在新生成的真实运行中用方向键把 `(0,2]` 的终点改为 0。修复前 Safari 的可访问性标题可能保留旧计数。修复后按 Tab 聚焦新结果，完整字幕为「标题级别 4，这个区间没有搬迁记录。」 |
| Safari 学生导出 | 键盘选择两个真实事件、填四项解释，提交后按回车下载 `EcoSimEdu-迁移作答.json`。旁白读出「双来源解释已保存，待教师复核」「导出迁移作答，按钮」。 |
| Chrome 教师导入、复核、导出 | 从空复核页打开原生文件选择器，确认正确文件后按回车导入。旁白读出「双来源作答已核对并导入」。用键盘打开原事件 4 和 147，返回后四项各给 2 分、选达标、填写评语并保存。保存后原生焦点标题显示「教师复核已保存。8 分，达标。」随后旁白读出「导出教师复核，按钮」，回车下载 `EcoSimEdu-教师复核.json`。 |
| Safari 学生导回 | 用键盘打开选择器、输入回传路径并确认。按回车导入后，旁白完整读出「教师复核已导入。8 分，达标。」刷新后仍显示四项分数、总分和评语。 |
