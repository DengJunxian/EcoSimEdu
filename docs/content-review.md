# 双向拍卖首课内容复核

核对了 Smith 1962 年《Journal of Political Economy》原始论文的出版条目，以及 Smith 的诺奖自述。原文用于建立实验身份和制度背景。教学运行的数值、角色、费用、报价策略和种子由本项目定义并生成。课程资料提供来源对应范围，源链接用于拓展阅读。核心内容、概念和形成性反馈都随本地安装提供。

首课让学生检验价格、私人价值、真实成交与剩余之间的关系。需求估值干预和收费干预独立，模型报告费用作为转移，并区分可实现剩余上界与实际余量。固定报价 96、种子 1962 下，三组成交价范围均为 95–97 代币/件；需求干预使一件额外商品成交。四回合有限交易与报价策略决定本课结论的适用范围。

七步、题目、检查点、角色与情景参数以 [课程配置](../cases/double_auction/case.json) 为准。两份写作技能用于将先说观察、接着给规则和条件用于学生题目和模型说明。
