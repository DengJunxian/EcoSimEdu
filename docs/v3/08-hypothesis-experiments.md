# WP08 · 假设驱动的课堂与进阶实验

2026-11-20。

学生在「反事实实验」页先选政策、预测结果方向，再按需写下 240 字符以内的假设。预测方向仍是运行条件。假设草稿进入本机检查点。运行成功后，结果卡展示原假设。运行失败时可带着原草稿重试。再次开始对照时可以写新的假设。

导出的实验卡保存学生入场动作、政策、预测方向、假设和种子。每对结果有两个独立的运行标识、摘要及指标来源。导入时本机按原输入重新运行并核对整张卡。历史无假设的实验卡继续使用既有恢复流程。假设文字随卡导出，参与计划摘要计算。

本机完成课堂对照后可以进入两项进阶任务：

- 「自选参数实验」按当前课程开启既有参数台。可填写研究问题和判据，选择有效的处理变量、控制条件与种子，再导出对照和两组源运行。
- 「多角色模型实验」可运行规则参考，或在本机已设置供应商和预算时主动启动模型决策。模型动作由已有执行层校验。回执按实际情况标明规则、模型或混合执行。

静态构建保留课堂假设、规则对照与实验卡导出和恢复。进阶页面依赖本机服务。

## 验收

- 构建、68 项前端测试和 364 项契约与机制测试通过。测试涵盖运行失败保留草稿、运行后锁定假设、修改实验卡后拒绝恢复，以及旧卡重算兼容。
- Chromium 39 项、WebKit 18 项浏览器回归通过。碳配额课在两种浏览器完成假设草稿刷新、同种子运行、导出和恢复。Chromium 另外前往参数台运行 5 项回归，以 4 门课验证多角色规则参考、原事件和回执。
- 纯静态构建在 390 和 1440 像素完成柠檬市场带假设的规则对照及刷新恢复，全程无 API 请求。模型相关契约使用供应商替身核对合法动作、超额和回退记录。
