## 实施门槛

- M1 以 WP00–03 的端到端课为准。八阶段接口、学习级别、讲解风格、预算和自动讲解按实际服务能力逐步接入。
- M2 以 WP04–06 的三旗舰为准。各课保留证据与机制身份，真实分叉以原引擎世界状态重算。
- M3 以 WP07–10 的十二课和发布验证为准。公开 BYOK 需要单独的部署和授权设计。学生学习效果需要单独研究，本轮验收覆盖软件行为与教学材料。

## WP02 验收路径

1. 在居住隔离完成预测并观察一次迁居。后端按发布课程、引擎版本和规则输入重算，核对浏览器回放前缀并为当前公开焦点签发短时凭证。
2. 询问当前搬迁的局部变化。数值从引擎及已核对的邻域计数投影，讲解引用能回查这次实际搬迁。缺少可信运行时提供作者定义和观察提示。
3. 测试未来结果请求、未授权视角、伪造事件和数值、连接失效与超时。用相同的合法证据回退作者讲解，保留原预测、尝试和评分。
4. 故事核对发布材料，反事实核对两组收尾。用自然问题与断流验证同一证据权限和回退，然后推进八阶段自学与跨课程迁移。
