# WP05 · 居住隔离轮间分支

2026-11-20。先在居住隔离验证可恢复的中途行动，再据此评估硅谷银行挤兑的队列状态和双向拍卖的订单簿状态。

## 课堂入口

在八阶段课堂完成开局选择，进入「机制与涌现」。打开「在轮末再搬一次」，走到可分支的轮末。从符合迁入阈值的空格中选一个目的地，预测期末同组邻接比例的变化，再运行分支。可以按共同的轮末和各自收尾比较，也可以查看分支迁居的原事件。轮末缺少另一组观测时保留缺失。

完成后刷新，可以恢复最近一组分支和原预测。在「反事实实验」仍可查看它，也可继续原有的阈值实验、独立应用和迁移。下载的证据记录含两组网格、事件、结果摘要及网格 SHA-256。原学习备份以原检查点格式一并保存可重算的分支参数。分支证据 JSON 用于查阅和外部核对。

## 运行定义

- 检查点只能是已进入系统视角、已经揭示、自动更新仍会继续的轮末。学生在下一轮开始前额外行动一次。目的地必须为空并满足已有迁入阈值口径，计算邻居时扣除学生即将离开的原位置。这个额外动作是课堂实验，自动住户继续使用原来的阈值和搜索空位的规则。
- 浏览器从轮末网格重建位置表、空格集合与累计搬迁数，保留至该轮末的记录。分支记录新迁居，然后沿既有自动更新顺序推进。随机搜索用种子、轮次和住户确定，因此检查点包含恢复所需的轮次和空间状态。
- 两组共享开局选择、种子、人口、规则参数和检查点之前的每一帧。分支获得独立运行编号。轮末对齐依据实际更新轮次，收尾各用自己的原事件。主回放停在原轮末，导出和分支结果可通过各自的事件编号复核。

## 验收

本轮 62 项前端测试、353 项契约与机制测试通过。Chromium 的三旗舰定向回归通过 16 项，WebKit 的八阶段与分支回归通过 5 项。

开局选择搬到预留空位的课堂样例中，第 1 轮末为事件 73。选择第 1 行第 20 列，分支事件 74 记录 A001 的迁居，下一笔自动行动的数据与基线分开。期末同组邻接比例为基线 84.55%、分支 86.94%，相差 2.39 个百分点。

- `npm --prefix frontend run build` 和 `npm --prefix frontend test`。验证合法落点、人口守恒、前缀一致、原运行摘要、同参数复跑，以及从原进度备份恢复两组运行。
- `PYTHONPATH=. python frontend/tests/remaining_parity.py`。TypeScript 从检查点恢复，Python 从相同开局重放并在轮末执行同一迁居。12 组分支的 1,707 帧逐一核对；全矩阵 104 组、7,935 帧通过。已有居住隔离导师的 211 条搬迁前缀与 8 条收尾摘要仍能核对。
- `python -m pytest -q tests/contracts tests/mechanisms`。包含 Python 分支的逐事件人口、邻居计数、落点阈值和终局指标复算。
- `python -m pytest -q tests/e2e/test_schelling_fork.py tests/e2e/test_lesson_flow.py`。Chromium 与 WebKit 均验证键盘选择、未预测时的禁用状态、精确检查点、刷新、角色视角和导出。无后端静态构建在 320、1440 像素完成四条独立路径，页内没有 API 请求，四次 axe 扫描均无规则发现。
