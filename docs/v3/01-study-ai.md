# WP01 · 本机 AI 导师连接

## 学生路径

从本机 `/explore/` 选择「连接 AI」，或选择「暂用离线」。已跳过的浏览器通过课堂和课程地图的「AI 导师」返回设置。连接页提供 OpenAI、DeepSeek、Claude、Gemini 和通义千问的已有预设模型。选定供应商后，在密码框输入对应密钥，再主动选择「发送一次连接测试」。测试可能产生少量费用。页面按供应商报告展示 token 用量，实际费用查供应商账单。通过后可进入居住隔离，测试失败时课程入口同样可用。

## 服务契约

- `GET /api/ai/providers` 返回固定供应商及预设型号。`GET /api/ai/status` 返回当前会话的最后测试结果、用量和剩余次数。
- `POST /api/ai/test` 接收 `provider`、`api_key` 及显式 `confirm: true`。服务端向固定供应商发送一次最多生成 64 token 的测试，使用空的课堂观察。各供应商只有其现有预设型号。
- `DELETE /api/ai/session` 清除当前会话和连接记录。会话自首轮测试起最长 60 分钟，服务重启时重新配置。Cookie 只有随机会话标识，带 HttpOnly、SameSite=Strict 和 `/api/ai` 路径限制。测试每会话最多 5 次，间隔至少 3 秒，每个供应商本机进程每小时最多 20 次，连接测试与讲解请求共用该限额。
- 学生授权的 V3 Key 只进入同源回环服务内存。验证失败后销毁本次 Key。切换供应商需要重新输入。配置响应使用 `no-store`。旧 `/api/local-model` 与 V3 会话相互独立。

建议以文档中的 `--host 127.0.0.1 --no-proxy-headers` 启动单进程本机服务。公共构建继续提供规则课程。模型名是随应用发布的预设，实际可用性由当前账户和连接测试决定。已提交给供应商的测试可能在离开页面后完成并计费。

## 本轮验收

- 两套本机生产构建和 Pages 构建通过。57 项渐进课堂测试、346 项 Python 机制与契约、119 项 Chromium 端到端测试全部通过。新增契约覆盖显式同意、同源检查、恶意或超长字段、调用上限、会话隔离、切换失效和清除。
- Chromium 与 WebKit 分别在 320、390、768、1440px 通过首次跳过、键盘操作、模型切换、测试失败后重试、刷新状态、清除和开课。连接状态在浏览器自动化中采用测试回执。
- 另用真实 Chromium 和 FastAPI 串通同源请求，供应商 HTTPS 传输由替身接管。确认点击前无请求，提交后一次调用，刷新读到结果，独立档案读不到连接，清除即时生效。测试 Key 在浏览器存储快照、页面及 URL 中均未出现。
- Pages 独立构建的浏览器走查打开十二课目录并进入居住隔离。手工访问 `?view=ai` 仍显示规则课程且无 AI API 请求。
- 课程阶段讲解、价格和用量预算、真实供应商连通及账单属于后续验收。当前记录使用测试凭证和供应商替身。
