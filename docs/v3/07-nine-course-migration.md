# WP07 · 九门课程接入八阶段自学

2026-11-20。课程地图为十二门课提供「八阶段自学」，旧四阶书签仍打开原课堂。学习者在新入口可继续读取同一课程的已有运行和检查点。新手读一个开局例子，标准深度从一条可核对的观察线索开始，进阶深度先说明怎样保持共同条件。

九门课使用各自的领域面板、规则运行和已发布题库。学生在机制阶段可从已揭示的指标表定位原事件，在实验阶段先预测再运行对照。保存双来源解释后可作答独立题，提交后到新情境完成迁移。复习安排按本机日期读取。

「故事」的本机学习助手提供角色、观察线索和制度口径三种讲解。材料来自发布的开局任务、模型假设和课件，结果可展开原来源。课程编号和版本绑定到证据范围。供应商在这些作者材料中选取讲解步骤和追问，故事阶段只读取发布材料。离线与公开静态课堂直接提供作者材料、规则实验和题库。

## 运行事件讲解

九门新迁移课程在「机制与涌现」暂停到可讲解的事件时显示「讲解当前事件」。学生可选择解释这条记录、找回查线索、核对前后读数，或用自己的话问这三类问题。「查看原事件」展开同一时点的回放记录。播放、重置或换到其他事件时，当前讲解随焦点更新。

对照运行结束后，可以从反事实实验页核对课堂种子的政策组事件和已揭示的基线组事件。两组选项各自引用原运行。即时录取、付费核验、隐藏前序行动使用各自的规则说明。

每课声明可讲解的事件类型、公开指标及个别公开交易字段。本机服务用发布种子、学生选择和所选政策复算，再核对当前回放前缀的事件类型和公开读数。复算通过后，短期授权绑定课程版本、运行、事件、本机会话和来源。供应商收到所选事件、相邻两帧的公开读数、作者解释及追问选项。例如碳配额可核对买卖双方与配额编号，闪电崩盘可核对成交单号、撤单数量和库存阈值。信息级联只在决策事件讲解公开后验和行动计数，私信号、私人后验及终场答案均留在原回放。

自由提问由本机识别当前事件的规则、来源或读数问题。问题原文保留在本机。请求其他事件、私有资料或无关主题时直接返回范围提示。模型只选择已核对的步骤和追问。遇到模型未连接、超时或结果校验失败，本机可返回作者讲解。缺值显示为未定义。静态版本可直接用原领域面板和指标表回查原事件。

## 验收

- 构建和 68 项前端测试通过。363 项契约与机制测试通过，包含九课故事授权、绑定错误课程时拒绝请求，以及故事材料的揭示范围。
- Chromium 通过 19 项，包含九课全程、原四阶信息级联续学和三旗舰回归。WebKit 通过 11 项。九课各自完成一次同种子政策对照、两条证据的解释、独立应用、迁移和次日复习。
- 1440 像素的 Chromium 从静态文件服务完成九课全程，浏览器没有发送 API 请求。390 像素的 Chromium 与 WebKit 共完成 18 次工作台 axe 扫描，均无自动违规项。对 axe 无法判断的短 SVG 标记，按字色和节点底色复算，最低对比度为 8.47∶1。
- Python 与浏览器对照矩阵的 104 条轨迹和 7,935 帧一致，包含九课、居住隔离与其迁居分支。

复跑使用 `npm --prefix frontend run build`、`npm --prefix frontend test`、`python -m pytest -q tests/contracts tests/mechanisms`、`python -m pytest -q tests/e2e/test_migrated_lesson_flow.py tests/e2e/test_lesson_flow.py` 及 `PYTHONPATH=. python frontend/tests/remaining_parity.py`。WebKit 用 `CIVITAS_ED_WEBKIT=1` 运行 `tests/e2e/test_migrated_lesson_flow.py`。

接通运行事件讲解后，九课所有发布种子基线开局动作共比对 563 个可讲解的事件证据前缀。68 项前端测试、364 项契约与机制测试、26 项 Chromium 回归和 14 项 WebKit 回归通过。接口测试覆盖错误事件、摘要错配、终场资料和错误会话来源。信息级联、碳配额市场及闪电崩盘通过两种浏览器的导师请求、回查焦点和退出校验，六次 390 像素导师区 axe 扫描均无规则发现。三课也通过静态事件回放，无 API 请求。Chromium 回归另包含居住隔离搬迁导师 `tests/e2e/test_relocation_tutor.py`。

加入政策组与自由提问后，九课基线组和政策组共核对 1,046 个公开事件证据前缀。接口验证跨组或跨事件的授权失效、越界问题在本机返回，以及隐藏前序行动时公共后验不变。信息级联、学校匹配与碳配额市场通过了 Chromium 和 WebKit 的政策组问答、原事件回查和切换清除。390 像素下对政策组导师区做了六次 axe 扫描，均未发现违规项。
