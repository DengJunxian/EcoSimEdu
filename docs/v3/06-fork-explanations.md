# WP06 · 分支解释、学习证据与复习

2026-11-20。居住隔离、硅谷银行挤兑和双向拍卖的八阶段课堂都能用中途分支完成解释作品。完成分支后进入「反事实实验」，选择「用中途分支写解释」。同一课堂的政策对照仍可用于原来的解释路径。

## 从两条原事件到一份解释

解释卡对应一项已发布的学习目标，并保留学生原先的动作预测。学生从基线和分支各选一条原事件。分支引用限定在检查点之后。填写主张、机制、算术、配对结果、适用条件，以及另一个可核查的解释。双证据离线自查提醒学生逐条核对支持的主张、时点和口径。

原实验笔记和备份使用同一个版本化容器。新记录还保存检查点与动作参数。查看原事件时，用已发布的规则重建对应运行，再核对运行编号、版本、摘要、事件号及帧位置。教师可导入原有「导出含解释的结果」文件，复算两组来源。SVB 的核对卡按所选子事件显示其前后账表数值。

## 评分与复习

写解释和保存自查只记录作品及反馈。独立作答、提示曝光、答案曝光、重复尝试和复习仍通过原学习仓库记录。题目继续由固定规则核对，复习时间仍由原规则安排。已到期的目标在课堂显示「待复习」。

拍卖的浏览器验收在政策对照和中途分支并存时切换解释来源，再刷新恢复。保存分支解释、生成自查并备份时，档案中的题目作答为空。提交独立应用题后，继续做迁移题，推进到次日便可从到期安排打开复习。

## 个性化复习

复习页先读本机到期安排，再读取该学习者在对应课程、内容版本和目标上最近一次有结果的独立应用题记录。三门旗舰课各新增一道有独立题目身份的平行题，分别练习邻居比例分母、提款申请与实付的账表影响、拍卖费用与三方剩余。近期答错、用过提示、同题重做或独立性待确认时，优先呈现平行题。已能独立答对或尚无可用记录时，呈现目标的常规复习题。其他目标使用各自已发布的短题。

本机版允许学生主动点击「请 AI 选题」。请求仅含学习目标、内容版本和最近作答的正误、提示使用、证据类别。供应商在该目标的已发布短题中推荐一道，服务端核对题目身份。换题仅在当前页面生效。调用失败时可以直接继续当前题。静态版由本机规则选题。

题目由固定评估器核对，提示按题目变式记录。作答和完成复习安排在同一事务保存，另一页面推迟或暂停后，旧页面的提交会被拒绝并重新读取安排。完整备份可恢复题目身份、作答、帮助曝光、规则评价和完成状态。

## 五个概念微课

从八阶段课堂的「预备」「独立解释」或「迁移与复习」展开「概念微课」。居住隔离提供百分比与分母、单变量对照与随机性。硅谷银行挤兑提供存量与流量、概率与条件信息。双向拍卖提供边际与总量。

同一微课依次提供直观例子、完整示范、小步练习和新情境题。可跳过示范和小步练习，也可随时返回当前课堂。示范只标记小步练习的帮助曝光。新情境题按自身的提示、答案和重复作答记录判断证据。课堂主线负责判定课程目标的独立达标，微课两道题均保留为有版本的教学练习。

微课复用本地评分、活动和备份。打开和退出微课时，原题输入、课内阶段、运行编号、观察位置和揭示上限按原记录保留。微课支持公开静态构建。

## 三旗舰在线审阅

学生可在课堂或实验笔记对三门课的已保存政策对照卡、中途分支卡请求在线审阅。点击才提交各栏前 160 字。浏览器先核对笔记的原事件引用，本机服务再用发布课堂的种子和规则复算两组运行并核对事件前缀。分支必须引用检查点后的事件。模型供应商收到作答摘录、作者量规和这两条事件的摘要。

- 居住隔离核对迁居前后的邻居计数及各自阈值。
- 硅谷银行挤兑按原顺序拆出申请和实付的单笔交易。引用轮内事件时，摘要展示该笔前后的现金、待付和权益。例如「3/1」核对第 3 轮第 1 笔事件。
- 双向拍卖核对逐笔订单和订单簿。撤单摘要带实际订单号，成交摘要带买卖两单、定价在簿单、成交价和费用。

导师按学生作答选择一条作者追问，维度包括证据、机制、计算、适用条件与替代解释。追问可跳回两条原事件。无连接、超时、次数耗尽或回复校验失败时显示作者自查。审阅使用已有导师会话额度。本机只在当前请求中处理摘录，追问只显示在当前页面。独立评分由原题目核对器负责。

## 验收与复跑

分支解释首轮通过 67 项前端测试、358 项契约与机制测试、16 项 Chromium 定向回归和 8 项 WebKit 定向回归。三门课在两个浏览器和 320、1440 像素宽度共完成 12 条静态路径，解释表单的 axe 扫描无规则发现。

- `npm --prefix frontend run build` 和 `npm --prefix frontend test`。覆盖三课解释从无进度的档案中恢复、旧 v1 笔记和错配运行身份拒绝。
- `python -m pytest -q tests/e2e/test_fork_explanations.py tests/e2e/test_lesson_flow.py tests/e2e/test_domain_notes.py tests/e2e/test_education_activities.py`。覆盖三课浏览器解释、两条原事件、全量学习档案导入、教师复算及篡改分支检查点拒绝。原有帮助、独立与复习记录由课程回归一并核对。
- `CIVITAS_ED_WEBKIT=1 python -m pytest -q tests/e2e/test_fork_explanations.py tests/e2e/test_lesson_flow.py tests/e2e/test_domain_notes.py`。跑同一组跨浏览器的关键入口。
- `python -m pytest -q tests/contracts/test_local_model.py`。用供应商替身检查错配事件、非法追问、超时、会话额度、未发布复习题及超出当前目标的推荐。
- `PYTHONPATH=. python frontend/tests/remaining_parity.py`。额外核对 12 组居住隔离迁居分支的完整证据前缀摘要。
- `PYTHONPATH=. python frontend/tests/svb_parity.py`。核对 18 条基线或政策运行及 18 条暂缓提款分支的交易前缀摘要。
- `PYTHONPATH=. python frontend/tests/auction_parity.py`。核对 21 条基线或政策运行及 43 条撤单分支的订单与证据前缀摘要，包含供需无交叠情境。

三课接通后，67 项前端测试及 359 项契约与机制测试通过。Chromium、WebKit 各通过 12 项课堂与实验笔记回归，覆盖课堂政策对照、恢复的分支解释和改动引用后拒绝请求。供应商链路用替身验证。三课在两个浏览器的 320 像素在线审阅区共完成六次 axe 扫描，均无规则发现。公开静态构建在 320 像素下通过三课的分支、离线自查和学习档案回查，审阅入口按部署模式隐藏。

个性化复习接通后，68 项前端测试和 360 项契约与机制测试通过。`python -m pytest -q tests/e2e/test_lesson_flow.py tests/e2e/test_education_activities.py` 在 Chromium 通过 14 项。`CIVITAS_ED_WEBKIT=1 python -m pytest -q tests/e2e/test_lesson_flow.py` 通过 8 项。两种浏览器验证拍卖错答与银行提示触发平行题、断网继续作答、到期变更拒绝旧提交、模型推荐及完整档案恢复。四次 320 像素复习区 axe 扫描无规则发现。居住隔离在 320 和 1440 像素完成从静态课堂错答到次日离线复习，浏览器没有发送 API 请求。
