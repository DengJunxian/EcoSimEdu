# WP02 · 居住隔离的阶段证据讲解

本机渐进版的居住隔离课在故事、微观观察、宏观观察和反事实四个入口提供预设讲解与自然语言提问。每次由学生主动请求，模型编排已核对的讲解步骤及追问。课内原材料可直接回查。

| 阶段 | 开启方式 | 讲解证据 |
| --- | --- | --- |
| 故事 | 在开局展开「先了解角色与规则」 | 发布案例里的合成社区、A001 的选择、已占邻格与开局阈值。可回查案例资料与模型假设。 |
| 微观及宏观观察 | 在公开的系统视角暂停于一笔搬迁，展开「讲解这次搬迁」 | 当前搬迁和前一帧，包含住户邻域和全图指标。可回退或定位至当前事件。 |
| 反事实 | 提交预测、运行对照后，展开「讲解课堂种子的对照」 | 两组独立的收尾事件、各自停止条件和期末数值。可回查基线和干预组的原收尾记录。 |

## 证据与权限

1. `POST /api/ai/tutor/scope` 按阶段校验固定字段。故事阶段只读发布课程和内容版本，观察阶段校验公开镜头和当前回放前缀。反事实阶段要求两组完整运行的 ID、收尾序号及摘要。
2. 反事实在服务端分别重算课堂固定种子的基准与干预组，核对相同的初始地图及 A001 开局动作。支持 30% 基线对照 0%、50% 或严格边界 100%。两组各自的期末指标与停止条件分别来自其原运行。启用附加种子时，导师这一入口继续讲解页面标明的课堂种子配对。
3. 核对通过后签发 90 秒凭证，绑定来源、模型会话及配置版本、阶段与当前证据。凭证留在请求中。`POST /api/ai/tutor` 再核验凭证与显式确认。模型接收允许的教学材料，输出讲解步骤及追问 ID。服务端核对 ID 与覆盖要求后渲染。原预测留在课堂的既有学习记录中。
4. 回退、续学、切换镜头或重新做一组对照时，下次讲解重新核对当前材料。角色镜头隐藏系统讲解。超时、无效模型输出或缺少连接时使用作者讲解。本机服务不可用时，浏览器仍可阅读已经加载的故事材料、原事件与对照结果。

规则课在浏览器运行。摘要和短时凭证核对可复算的课堂材料及导师访问范围。学生实际观看与作答行为以各自学习记录或独立研究采集为准。

## 自然语言问题与流式讲解

- 在「讲解方式」选择「自由提问」。故事可问如何数邻居，观察可问当前住户为何搬迁，反事实可问本组差值或停止条件。本机按限定的课堂主题匹配问题。无匹配、超出当前证据或提及未揭示结果时，界面给出此阶段的可问方向，供应商不会收到新调用。
- 自由提问的原文只在本机用于匹配，供应商收到规范化的主题和当前授权材料。成功回执按会话、证据和主题缓存，同一主题的改述可复用回执。课堂预测与正式作答仍由原流程保存。
- `POST /api/ai/tutor/stream` 与 JSON 讲解接口共用凭证、用量预算和缓存。浏览器先收到处理进度，再接收完整回复通过服务端校验后拆分的讲解步骤与结束标记。每项引文在显示前对应当前焦点。缺少结束标记或接收失败时，界面撤下不完整的讲解并保留原课程材料。
- 学生可停止接收或离开当前阶段。已发出的供应商请求继续计入预算，完成且有效时保留回执与缓存，避免同一主题重试发生重复调用。

## 供应商调用

每次动作最多向供应商发出一次请求，输出上限 192 token，当前会话最多发出 6 次讲解请求。连接测试与讲解共享同一供应商每本机进程每小时 20 次上限。相同意图和相同材料的成功讲解复用会话缓存，仍需新的有效凭证。微观与宏观阶段讲解同一公开搬迁时可共享已验证的编排。切换或清除模型连接时，旧配置的凭证失效。用量采用供应商回执，已离开页面的请求仍可能计费。
