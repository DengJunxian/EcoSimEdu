## 长回放实测

macOS 27.0 ARM64 的 Chromium。在同一课堂种子下复跑同一组基线与政策条件下的 201 个经济时点。分别用新浏览器上下文加载改动前后两个构建。在 390 CSS 像素加 4 倍 CPU 降速，前后各用 3 个独立上下文，每个上下文在曲线就绪后重复打开证据表 7 次。记录打开后第二次动画帧的时间和页面节点。

| 观测量 | 改动前 | 改动后 |
| --- | ---: | ---: |
| 折叠时挂载的数据行 | 201 | 0 |
| 展开时挂载的数据行 | 201 | 24 |
| 展开时的页面元素 | 1,596 | 538 |
| 打开至第二次动画帧中位数 | 32 ms | 32 ms |

本轮观察到 DOM 工作量下降。帧时间中位数相同。实验记录覆盖本机浏览器和 CPU 模拟，实际设备的性能待测。

## 回归结果与复跑

68 项前端测试和 364 项契约与机制测试通过。课堂浏览器回归覆盖首次使用、学习阶段、解释作品、概念练习与旧端导航，Chromium 45 项和 WebKit 40 项通过。两种浏览器的 58 次局部 axe 扫描均未发现违规项，其中八次对应四档屏宽下的长对照证据区。

- `npm --prefix frontend run build` 和 `npm --prefix frontend test`。
- `python -m pytest -q tests/contracts tests/mechanisms`。
- `python -m pytest -q tests/e2e/test_migrated_lesson_flow.py -k 'long_comparison or guided_hypothesis'`。长对照以 320、390、768、1440 CSS 像素运行，设置减少动画，核对 Tab、翻页、原事件、回首页和页面无横向溢出。恢复实验卡在 320 像素复测。使用 `CIVITAS_ED_WEBKIT=1` 可切到 WebKit。
- `python frontend/tests/experiment_workbench_browser.py http://127.0.0.1:8776/explore chromium 320`。可换 `webkit 768`，覆盖三个种子、各组原记录、实验卡恢复、无成交、银行负权益、居住隔离和附加种子重试。
