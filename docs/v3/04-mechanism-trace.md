# WP04 · 四层机制追踪

2026-11-20。三门旗舰课的「涌现显微镜」由微观主体、主体间互动、局部聚合和宏观结果组成。在四阶课堂的宏微观阶段或八阶段自学的「机制与涌现」打开显微镜。用指标表或曲线挑选时点，再从宏观卡回查具体的贡献事件。

## 运行证据

| 课程 | 局部聚合如何核对 | 课堂样例 |
| --- | --- | --- |
| 居住隔离 | 从搬迁事件汇总搬迁者与受影响邻居的计数变化。每对邻接在两端各计一次，除以二后和前后网格重新计数的差值核对。 | 事件 1 涉及搬迁者和 14 户邻居。同组邻接对从 529 减至 527，已占邻接对都是 1,051。同组邻接比例从 50.33% 降至 50.14%。 |
| 硅谷银行挤兑 | 用真实流水重构每笔事件前后的累计申请、实付、待付和现金。只有可与轮末账表对平的贡献才提供反向定位。 | 事件 1/2 的申请使待付从 0 增至 19，现金为 100。事件 1/4 的实付使现金从 100 降至 81。两笔通过原入队申请相连。 |
| 双向拍卖 | 用当帧订单簿显示买卖挂单数和两侧最优报价，链接到真实提交事件。已撮合订单及结算价使用成交记录。 | 事件 4 可回查报价 96 的 O001 和报价 78 的 O003，累计成交从 0 增至 1。供需无交叠时，买价 35、卖价 78，成交价为空。 |

整数账务核对采用引擎的实际流水。显微镜提供后续已揭示的申请、报价或邻域信号，证据链接回到同一次规则运行。SVB 按轮揭示，贡献清单对应当前已揭示的整轮，局部表对应当前选中的单笔流水或轮末。角色视角只展示角色获准看到的证据。运行编号处可核对模型身份、种子和版本，导出保留相同的已揭示范围。

反事实阶段沿用三门课原有的同种子规则对照。居住隔离改阈值，SVB 改现金配置或信息网络，拍卖改收费或需求条件。逐条冻结传播关系及从中途检查点重算分支需要后续实施。
