# WP05 · 双向拍卖的中途撤单分支

2026-11-20。八阶段课堂在「机制与涌现」提供「试一次中途撤单」。当一位规则主体的报价和撮合均已处理完毕，且 B01 的买单仍在簿上，学生可预测收盘成交量，再撤回这张买单。基准市场与供需无交叠场景都可试验。

## 检查点与续学

浏览器从检查点恢复订单簿及同价时的入簿顺序、账户、成交累计量、平台收费、最近一笔实际成交和原自动报价的顺序与扰动。两组共用种子、入场限价、开局账户和已发生的每一帧。撤单在分支单独记录，随后从下一位规则主体继续报价和撮合。已成交订单及未完成撮合的中间帧都无法发起撤单。

学生可选择共同的轮末或收盘，查看全市场累计成交、B01 已成交数量和最近成交价，也可回查撤单及各自下一笔成交。普通回放的检查点和揭示范围保留在基线。进度保存最近一组分支及原预测，重新打开后可继续查看。导出包含基线和分支的事件、订单簿、账户、源事件指针以及订单簿和账户的 SHA-256 摘要。

## 课堂样例

B01 以 96 代币限价开局。在事件 2 后，订单 O001 仍在簿上，分支事件 3 记录主动撤回该单，账户现金和持仓仍分别是 500 代币和 0 件。基线在事件 4 以 96 代币完成 B01 的交易，分支从未成交这张订单。收盘时全市场累计成交分别是 6 件和 4 件。

供需无交叠的 35 代币样例中，两组收盘成交均为 0，成交价与效率保留为未定义。
