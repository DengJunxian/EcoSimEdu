# WP03 · 八阶段自学

2026-11-20。三门旗舰课共用八阶段页面和续学方式。学生从课程地图选择「八阶段自学」，也可从本机导师设置直接打开居住隔离。原四阶入口、专用历史链接和教师展示继续使用各自的流程。

## 从预备到复习

| 阶段 | 学生要完成的事 |
| --- | --- |
| 预备 | 选择新手、标准或进阶。预备材料分别使用短例、核心任务和证据提示，后续观察或实验提供对应的引导。 |
| 故事 | 阅读本人角色、制度背景和资料来源。SVB 页面同时给出史料和教学模型的身份。 |
| 预测与决策 | 居住隔离和 SVB 先记录预测，再选择行动。拍卖题的预测依赖限价，先记录限价，再预测该报价能否成交。进入观察时运行。 |
| 仿真观察 | 选择一个主体，单步核对事件和行动约束。 |
| 机制与涌现 | 从显微镜、指标曲线和已揭示事件追踪主体行动怎样汇总。 |
| 反事实实验 | 改一项条件，先预测再运行，核对相同开局、真实源事件和差异。 |
| 独立解释 | 从两组运行各取一条原事件，保存解释卡。提交一道独立应用题可进入下一步，评分和帮助曝光仍由原题库记录。 |
| 迁移与复习 | 在新情境中应用机制。首次独立证据仍按原规则安排复习，可从本机复习页进入。 |

## 恢复与证据范围

阶段由原引擎会话和版本化的学习进度共同决定。旧链接可直接打开，旧记录按已有阶段及有效运行恢复。新入口继续使用原检查点和备份，保存讲解深度、尚未提交的预测、此次记录的时间和观察位置。旧记录里缺失的时间留空。仅含预备进度或预测草稿的新检查点需要 V3 读取。两个标签同时学习时，过期标签无法覆盖更新的检查点。

导航可回看已完成阶段。观察回看使用离开该阶段时的位置，机制回看使用当时已揭示的记录范围。反事实通过已核对的运行身份恢复，独立解释依赖相同对照下的证据笔记。个人作答、迁移和复习使用已有学习档案。

居住隔离沿用上一包核对过的故事、公开搬迁和配对收尾导师。讲解、引导和算式三个入口复用同一证据契约。本机无模型连接时可用作者内容完成课程，公开静态构建通过本地题包完成全部流程。

## 验收结果

本轮 58 项前端测试、352 项契约与机制测试及 127 项浏览器回归通过。新增的三门离线路径和居住隔离连接路径在 Chromium、WebKit 各通过 4 项。仅使用静态文件服务时，Chromium 完成三门课的迁移与复习，验收期间没有 API 请求。居住隔离预备和决策页在 320、390、768、1440 像素宽度的 axe 规则扫描均无发现。

## 复跑

- `npm --prefix frontend run build` 与 `npm --prefix frontend test`。检查生产构建、旧书签兼容、早期草稿备份及并发保护。
- `python -m pytest -q tests/contracts tests/mechanisms`。检查经济规则及本机 API 契约。
- `python -m pytest -q tests/e2e/test_lesson_flow.py` 与 `CIVITAS_ED_WEBKIT=1 python -m pytest -q tests/e2e/test_lesson_flow.py`。三门课逐阶段测试暂停、回看、续学、独立题、迁移和次日复习。居住隔离另测本机 FastAPI 会话和确定性的模型替身。
- `VITE_ECOSIM_PAGES=1 npm --prefix frontend run build`。仅用静态文件服务，在 Chromium 完成三门八阶段路径，确认没有 API 请求。
