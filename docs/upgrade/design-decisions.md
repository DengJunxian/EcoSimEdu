# 学习首页与导航

首页优先回答三个问题。首屏用报价、提款和搬家说明学生能做什么。已有本机进度时显示实际课名和阶段。案例卡用“问题 + 开局行动”帮助选择，时长、材料身份与任务取自已发布案例包。

保留纸白与深绿，正文沿用无衬线字体栈，标题使用本机宋体风格衬线字体。首页与案例库共用课程卡，窄屏布局收成单列。主操作使用深绿实底、至少 44 像素的触控目标和统一的键盘焦点环。拍卖、网格与银行关系图用简单矢量标示机制结构，首页示意图配有说明，案例图由相邻的案例问题和行动提供文字语境。教学难度是本轮人工编排：开局选择容易理解的五课列为入门，其余列为进阶。这个字段和筛选器使用同一口径。

| 入口 | 可操作内容 |
| --- | --- |
| `/` | 进入双向拍卖、继续本机草稿、浏览六门代表案例 |
| `/cases` 和 `/cases/{case_id}` | 筛选 12 门已发布案例，阅读问题、开局选择、背景和出处，进入课堂 |
| `/paths` | 按已有课程知识地图查看四条路径 |
| `/notes` | 查看新旧学习记录，打开已保存运行，导出笔记 |
| `/experiments` | 查看现有模型实验设置及本地模型服务状态 |
| `/learn/double_auction`、`/learn/svb_run`、`/learn/schelling_segregation` | 三门新版旗舰课堂，含可恢复的场景地址 |
| `/?case=double_auction` | 原版双向拍卖课堂、原笔记与导入入口 |

使用原生网页链接与浏览历史。生产服务针对明确页面路径返回同一个前端入口。旧 query 运行、时间点、原始事件及边界实验仍按各自的参数加载。遇到失效运行时保留学习记录并给出笔记导出入口。首页继续学习显示有进度的新版课堂，有记录时间时按最近更新选择。旧新版拍卖草稿缺少时间时仍可续学。只有原版记录时，继续学习按发布目录选择首个尚未完成的课程。

Chrome 在 1440、768、390、320 像素宽度下走查首页。新导航测试同时覆盖选课、生产刷新、前进后退、继续原版课堂、原版笔记导出、保存运行与真实 404。与原先打开即进入双向拍卖不同，首访可先按经济问题选课，也可从首页直接进入新版首课。
