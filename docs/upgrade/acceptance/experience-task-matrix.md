# 可观察体验验收任务矩阵

适用于 EcoSimEdu UP00—UP11 升级。**以下全部为目标与待执行任务，不是本次已通过结果。** 现有基线测试、此次浏览器走查、目标 SVG 设计和未来升级验收分别记录。每次执行记录提交、case/version、run/seed、环境、结果及证据路径。

“自动”指可重复的机制/合同/浏览器断言；“人工”指真实操作及经济含义/视觉质量复核。两者不能互相替代。下列 28 项既覆盖通用能力，也要求十二课各有真实领域动作。

## 执行与关闭规则

1. 三个旗舰先执行 T03—T13 相关项形成可评审版本；十二课完整版必须再通过 T02、T14—T22，不能用“同组件”免除逐课验收。
2. T24 的四课为公共品、SVB、信息级联、GameStop。每课验收针对已声明模型角色与轮次，不声称全社会每个主体都调用 LLM。无密钥时可验证接口、规则和失败路径，真实 API 项保留“未执行”。
3. T25 不承诺尚未实现的跨进程自动续跑；如未来声称支持，必须额外验证完整 checkpoint 含 RNG、队列、记忆、账本和未决请求，防止重复结算。
4. 性能与任务时间为工程目标；首次有效操作约90秒、异常到主体不超过3次主要选择可用走查检验，但没有真实学习者研究前不声称提高理解率。
5. 自动化侧重点为有辨识力的失败条件：未来事件可见、主体身份丢失、反事实错位、错误支付、伪造引用、重复结算等。仅“点击后文本存在”不足以通过。
6. 结果使用通过/失败/受阻/未执行，附短证据和责任包。不得以旧版本报告、新版静态设计或历史 API 回执代替当前版本结果。
