## 回放与窄屏补验

- 此前单次定位后仍显示终点帧的现象，在原用例重复运行 20 次时未复现。加入 750 ms 的课堂接口延迟后，连续两次按左键得到事件 116、116。原因是加载中的滑块值被上一帧覆盖。修复后，两次输入依次选定 116、115，取消的请求无法覆盖已显示结果，随后准确定位稀疏帧。首次补验全量发现学校匹配用例把目标事件的加载说明当作到达确认，调整说明后定向与全量均通过。 [回归用例](../../tests/e2e/test_schelling_flagship.py)
- 新版 Schelling 全图置于局部滚动区，格子至少 24 × 24 CSS 像素，键盘和行列控件仍可选格。320、390 像素的 Chrome 模拟触摸点击第 20 列，选中项和行列读数同步，页面本身无横向溢出。 [W3C 指针目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)
- macOS Chrome 平台 AX 树暴露回放滑块的名称、焦点、数值及事件描述。按左键后从事件 1 更新到开局事件 0，行列下拉控件有独立名称。首页和 SVB 中九处 axe 未自动判定的 SVG 标签，按实际背景和浏览器计算样式复核，最低 6.49:1，截图复核未发现标签遮挡。 [W3C 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

## Schelling VoiceOver 实测

macOS 27.0（26A428），系统旁白 10，Chrome 157.0.8103.79，在 390 和 1100 CSS 像素分别运行真实课堂。两次使用独立 Chrome 配置、loopback 服务和临时 SQLite，测试种子 1971，开局选择搬到标记空格。使用键盘事件操作浏览器，用 macOS 键盘事件打开并确认原生行列菜单。这里的朗读内容摘自运行中的 VoiceOver 字幕面板。 [Apple 字幕面板说明](https://support.apple.com/guide/voiceover/unac078/mac)

| 路径 | 实际播报及界面结果 |
|---|---|
| 回放滑块 | 焦点读出“当前事件，事件 1，回放事件，滑块”。左键到“开局，事件 0”，右键回到“当前事件，事件 1”。两次定位均显示对应事件。 |
| 行列选格 | 展开「按行列选格」，Tab 到「行」与「列」。用空格打开菜单，向下选一项并回车，分别读出“11，行”和“17，列”。选完列再按 Tab 到邻居列表，读出“B050 · 第 11 行第 17 列。同组邻居 2/7”，回车展开时读出“已展开”。 |
| 固定居民 | 回车激活「固定追踪 B050」后，焦点移到「取消固定 B050」并朗读该名称。回放从事件 1 退回开局仍追踪 B050。取消固定后，焦点返回并朗读「固定追踪 B050」。 |

初测行列菜单只播报数值，菜单关闭后发布到状态区的居民和比例未进入本次 VoiceOver 字幕。复验把当前格结果纳入紧随列选择后的邻居列表控件名称，保留原生菜单与原有播报区。曾尝试的额外状态角色造成旧版课堂状态区重复，撤回后旧版检查点回归通过。初测固定后只读“取消固定，按钮”，更新后的按钮包含被固定的居民编号。测试结束后将旁白恢复为关闭。 [浏览器回归](../../tests/e2e/test_schelling_flagship.py)

## 双向拍卖与 SVB VoiceOver 实测

使用 macOS 27.0（26A428）、系统旁白 10 和 Chrome 157.0.8103.79，在 390 和 1100 CSS 像素各测试一次。两课均使用独立 Chrome 配置、临时 SQLite 和本机规则服务。双向拍卖采用种子 1962、开局报价 96，SVB 采用种子 20230309、首轮提交工资提款。用方向键、Tab 和回车操作课堂控件，主体选择使用 macOS 原生下拉菜单键盘事件。下列播报摘自运行中的 VoiceOver 字幕面板。测试结束后将旁白恢复为关闭。

| 课程 | 路径 | 实际播报及界面结果 |
|---|---|---|
| 双向拍卖 | 回放 | 从事件 1 左移到事件 0 后，读出“事件 0，开局，市场开盘”。 |
| 双向拍卖 | 主体追踪 | 选择并固定 B02。定位卖单原报价可查看 S02，返回后仍是 B02，旁白读出“B02，查看主体”。解除固定后焦点留在主体选择器。 |
| 双向拍卖 | 事件证据 | 回车选中图上的 96 代币成交点，落在滑块并读出“事件 4，第 1 轮，成交结算”。从卖单回溯后读出“事件 3，第 1 轮，报价入簿”。 |
| SVB | 回放 | 焦点读出“第 2 轮，事件 5，回放事件，滑块”，左移时读出“第 1 轮，事件 4”。 |
| SVB | 主体追踪 | 原生下拉菜单读出“D05，固定储户”。回查消息来源和实付时，界面仍固定 D05。 |
| SVB | 事件证据 | 回查来源后读出“第 1 轮，事件 3，回放事件，滑块”。定位现金下跌后读出“第 1 轮，事件 4”，银行现金显示 100 到 68。 |

初测拍卖原报价按钮随事件切换消失，焦点掉到页面正文，旁白只读网页标题。SVB 的来源链接把焦点移到储户下拉框，现金下跌链接则留在原按钮，二者均未读出到达的事件。修复后，证据定位在新帧载入且用户未把焦点移到其他控件时，将焦点交给回放滑块。拍卖原报价按钮也注明买卖方向和事件号。延迟响应回归另复现了拍卖滑块连按丢步，修复后两次左键可从事件 4 定位到事件 2。 [拍卖回归](../../tests/e2e/test_auction_scenes.py) [SVB 回归](../../tests/e2e/test_svb_flagship_domain.py)

## 综合复核

- axe 4.14.0 扫描八项入口页面和十二课观察阶段，共 62 个状态。信息级联的行动按钮由可见文字与供读屏使用的说明共同生成名称。学校匹配的席位按钮与闪电崩盘的买卖档位增加可命名的分组。最终扫描未检出 axe 违规、整页横向溢出、浏览器脚本错误或外部请求。另在 320 和 1440 像素计算 40 处首页、拍卖、SVB 图表文字与底色的对比度，最低为 6.90:1。
- 所有使用全局导航的页面在第一个 Tab 提供「跳到主要内容」。回车将焦点移到当前页的主区域。新版、旧版、参数工具与旧运行链接均保留主区域入口。
- 延迟响应测试复现拍卖播放中打开原报价后自动返回成交帧，以及 SVB 等待逐步回放时丢失按钮焦点。修复后，证据跳转暂停自动播放，等待期间的回放按钮保留焦点并拒绝重复触发。最终在 390 和 1100 像素复验双向拍卖和 SVB 的旁白，在 390 像素复验 Schelling 的回放、选格和固定居民。测试结束后恢复旁白关闭状态。 [拍卖回归](../../tests/e2e/test_auction_scenes.py) [SVB 回归](../../tests/e2e/test_svb_flagship_domain.py)
- 新版双向拍卖按路由加载。Vite 报告的入口 JavaScript 从 500.37 kB 降至 461.83 kB，gzip 体积从 161.57 kB 降至 148.98 kB。

## 本机延迟样本

Apple M5，24 GB，macOS 27.0，Chrome 157.0.8103.79，1440×940，Chrome 无头模式。本机 HTTP 服务及隔离 SQLite，双向拍卖种子 1962、限价 96、148 个事件。浏览器计时包括 Playwright 控件等待和渲染。冷组逐次创建空浏览器上下文，暖组复用同一上下文及已生成的运行，浏览器路由监测时关闭了 HTTP 静态缓存。缓存定位计时为本机快照接口的客户端往返，首轮计算计时包括创建与启动两个 API 请求。

| 操作 | 样本 | p50（ms） | p95（ms） |
|---|---:|---:|---:|
| 空上下文打开首页至一级标题可见 | 12 | 51.6 | 58.8 |
| 已保存拍卖观察场景刷新至播放控件可见 | 30 | 45.2 | 48.7 |
| 同一拍卖运行的快照定位 | 30 | 6.1 | 7.4 |
| 同一场景切换 S02 和 B02 至固定控件可见 | 30 | 1.7 | 2.3 |
| 拍卖规则运行首次创建及计算完成 | 12 | 12.0 | 16.1 |

T27 在本机样本内达到 150 ms 选择、200 ms 缓存定位和 2 秒规则运行的工程目标。硬件、浏览器、并发和大图的不同组合需要独立采样。
