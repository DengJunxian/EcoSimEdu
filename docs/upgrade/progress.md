## 实际运行

仓库已有依赖时，构建并启动本地服务。常用端口为 8776。已运行旧服务的用户可用原有配置重启，沿用同一主机、端口、浏览器配置和 SQLite 路径读取原笔记和运行。

```sh
npm --prefix student-web run build
.venv/bin/python -m uvicorn services.simulation.api:app --host 127.0.0.1 --port 8776
```

首页为 /，新版三课为 /learn/double_auction、/learn/svb_run、/learn/schelling_segregation，案例库为 /cases，笔记为 /notes。原版拍卖通过 /?case=double_auction 打开，旧运行、时间和事件参数继续可用。新版使用独立的本机记录键，能从已有原版基准运行继续观察。案例、种子、引擎及旧运行文件保留原身份。原版笔记、对照和导入仍可在原课堂及笔记页读取。

多角色实验为 /experiments/multi-role，无密钥可运行四课规则参考。可选导师和多角色供应商调用默认关闭。/notes 可导入新版课堂 JSON，原运行和引用通过校验后才恢复草稿。升级、备份和恢复见[学生实验室](../../STUDENT_LAB.md)。
