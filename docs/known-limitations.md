# 已知范围与待验事项

| 事项 | 当前边界 |
|---|---|
| 部署 | 本地单机候选版。macOS 有干净安装和浏览器验收。Linux ARM64 在 Debian 13 和 Xvfb 上执行 Chromium 图形模式回归。Windows、Linux 实体桌面上的人工验证、校园多用户部署和跨网络服务待验。[RC4 验收](release/rc4-verification.md) |
| 高级实验 | OpenAI 四课各测基准情景一名角色的一个合法动作。DeepSeek 协议及预算逻辑有受控测试，真实账户待验。多角色、多轮与模型质量比较待验。模型响应保存哈希和结构化回执，供应商原文不随交付保存。 |
| 学习与教师 | 校内实际课堂和学习提升待研究。教师模式提供课堂展示、参考答案开关和预设导出。课程笔记逐课导出，恢复需要匹配的运行库。 |
| 性能 | 组合样本包含 500 主体 × 300 帧、同一帧 5000 条关系列表和 10 万条事件。RC3 已通过事件直达抽样和边界测试。5000 条线的网络图、通用 100 主体 × 100 tick 规则规格、跨设备基准、更大或并发运行、增量快照待验。RC5 的新格式大样本首次与重复定位均达到 200 ms。旧格式大运行继续使用原始校验逻辑，首次性能仍沿用原限制。[RC5 验收](release/rc5-verification.md) 当前回放提供逐步播放。 |
| 可访问性 | RC6 增加坐标选格、图表数据表和时间轴焦点回归。三条核心路径在 Chrome 五档宽度及 Edge 窄屏做 axe 和回流检查。RC7 在 Linux 的 Orca/Chromium 组合验证了回放标题、时间轴、行列选格与成交价表。VoiceOver、NVDA、全面 WCAG 2.2 AA 和完整浏览器矩阵待验。[RC7 验收](release/rc7-verification.md) |
| 来源和授权 | 12 课为合成课件、历史事件启发的教学模型或理论机制。候选库登记另外 14 条资料。归档配发教学配置、事件生成代码、生成数据和引用元数据。第三方原文及市场原始数据仍由各发布方提供。上游 HEAD 根目录未发现独立许可证文件，本归档按同一项目的本地交付处理。[来源与阅读范围](release/candidate-catalog.md) |
| 旧仿真 | 独立交付包聚焦教学。完整仓库的 Streamlit、IPC、C++、Ray 和实盘相关路径按 [WP00](audit/repository-audit.md) 的审计范围记录。 |
