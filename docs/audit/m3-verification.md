# M3 十二课基础模式验收

2026-11-16。运行环境为 macOS arm64、Python 3.12.13、Node 26.0.0 与本机 Google Chrome。沿用 M2 的本地服务端口、SQLite 与浏览器进度键。四条学习路径覆盖十二门已发布课程。六门新增课已经进入同一[课程目录](../../cases/catalog.json)；每课有七阶段、规则模型、背景来源、学生行动、基准和至少两组配对对照。历史事件用于解释研究问题，学生看到的运行数据为本地教学仿真。

## 验证

- **100 项机制与 API 测试通过**。其中 79 项机制测试和 21 项 API 契约检查。五类市场与制度的例子覆盖交割前库存保持、真实申报小规模穷举、供应链存量与流程、配额唯一缴回、可结算的成交和借券资产守恒。另扫过除首课整数报价外的 97 个提供给学生的动作与情景组合，检查播放检查点、证据可用性、同源种子、主体起源和时标。
- **26 项真实 Chrome E2E 通过**。十一门通用课程分别在 1440、390 px 走完；双向拍卖原有 1440、1280、768、390 px 分辨率保留。每条路径阻断外网请求，核查对照、证据、笔记、恢复与跨课程隔离。同步对照支持键盘定位，图中事件可打开本地证据页。终态保留柠檬市场实际成交、学校最终录取与信息级联揭晓后的指标。闪电崩盘与 GameStop 可从成交直接打开原始买单和卖单。
- 构建、Git 差异检查和 Impeccable 机械检测通过。全目录运行摘要可重新产生。模型 API 支出为 0。
