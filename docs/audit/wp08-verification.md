## 本地控制

- 服务端以两个币种分别维护累计测试额度，USD 100、CNY 100。一次实验至多一个角色决策、两个供应商尝试。每个尝试在发出请求前事务性占用保守额度。超时和未知计费保留占用，已返回用量的请求按已登记费率估算。级别为这一本地 SQLite 实验库的测试控制。
- 同时只运行一个付费实验。非法动作、超时和限流测试覆盖有界重试和显式规则回退。取消先于终态提交时，保存已经发生的请求用量，模型动作退出结果。过期运行进入中断状态，用户可以重开。刷新时按保存的运行 ID 查看状态；查询和重放不再次计费。
- 活动服务只绑定回环地址。API 写入同时校验来源、回环主机和客户端地址。模型收到的字段来自角色允许的状态；数值记账仍由课内规则完成。凭证只由服务端进程从环境读取，运行和报告仅保存必要的请求 ID、模型、用量和动作。
- 费用台账与学习进度沿用同一数据目录。当前预留按公开价格配置。切换供应商账户或复制数据库时，供应商总账户预算需要独立监督。
