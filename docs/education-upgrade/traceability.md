# 教育升级追溯

| 学生操作 | 权威输入 | 可追溯产出 |
|---|---|---|
| 打开一课 | [正式目录](../../cases/catalog.json)及[目标映射](../../cases/learning-outcomes.json) | 十二课、36 个目标；课件自身的来源、模型版本及教学习题身份 |
| 作答、求助、返回例题 | [内容合同](education-contracts.md)及[活动运行时](../../student-web/src/learning/activity-runtime.ts) | 课程及题目版本、呈现顺序、暴露、追加记录及确定性评价 |
| 回看原运行 | SQLite 结果及原课堂投影 | 事件序、时点、角色、结果哈希。前缀结果继续服从已有运行身份 |
| 比较处理并写解释 | [参数台](../../student-web/src/experiments/parameter-lab.tsx)及已有 compare | 事前预测、共同根、实际参数与同步观察点。解释结构和事实引用各有检查 |
| 延迟复习 | 当前课件版本的正式作答与本地日 | 到期日期、依据尝试、暂停及推迟。旧版本保留在历史档 |
| 备份或恢复 | [浏览器归档](../../student-web/src/learning/learning-archive.ts)及旧笔记入口 | 当前和旧版尝试、逐题帮助、活动、复习、作品及迁移收据。运行库用独立备份 |
| 教学展示 | 同一课件、预设及教学模型 | 教学活动页与隔离档案。展示作答不进入个人证据 |

经济引擎的 case/engine 版本与历史标识继续由原运行提供。应用版本为 1.1.0-rc.3。发布包清单记录实际 HEAD 与整个源文件集的 SHA-256。课堂反馈和焦点走查见 [收尾验收](closeout.md)。
