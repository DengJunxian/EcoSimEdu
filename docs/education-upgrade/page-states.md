# 自主学习的页面状态

## 回到上次进度

当我返回浏览器时，我想从上次停下的位置继续，避免重新报价或覆盖原预测。

- 首页有旧课堂记录时打开该课堂。全新浏览器直接提供案例和路径。
- 原场景地址可打开已到达阶段，新练习在该阶段恢复当前活动。
- 完整例题恢复后返回原题。回放位置、已揭示上限与固定主体沿用原课堂。
- 存储失败时给出恢复文案，继续原课堂或保留输入后重试。
- 教学展示使用独立位置和答题档案，返回个人课堂时读取个人进度。

## 用新题复习

当我完成一次规则题并再次回来时，我想知道是否安排了短练，检验自己还能否独立完成。

- 首次正式提交独立题后，按本地日生成次日复习。重复提交不增加待办。
- 首页至多显示一道已到期复习，标出课程和到期日。
- 到期后先显示新变式。提示写入暴露后展示。
- 可以推迟 1、7、21 天或暂停。历史尝试和能力证据继续保留。
- 同题的多次点击不计为新的独立应用。个人概念页可查看支持证据的日期。

## 转入下一门课

当我练过一个案例时，我想找到共享概念的下一门课，检验原结论在哪些条件下还能用。

- 路径说明目标、顺序和自查。案例仍可自由进入。
- 推荐取最近一次个人尝试对应的路径，有下一课时显示理由。
- 概念索引可搜索，详情链接先修与实际课程。
- 跨课练习覆盖支付与库存、邻域与消息、分配与资源成本三组条件辨异。
- 个人记录与教学展示互不占用进度。原案例库与实验笔记入口可继续使用。
