# 十二课学习任务与参考解审阅

课程目标、任务与迁移关系在 [36 项映射](../../cases/learning-outcomes.json)。每门 v3 包登记来源及内容版本，题目身份为本项目编写的独立练习。真实现象与历史判断仍由原课轨迹及来源支持。例题与解题交替、延后检索参考 WWC 学习组织指南。SVB 历史背景使用美联储多因素复盘，账表题使用本课规则。[WWC 官方指南](https://ies.ed.gov/ncee/WWC/PracticeGuide/1) · [美联储 SVB 复盘](https://www.federalreserve.gov/publications/2023-April-SVB-Executive-Summary.htm)

| 课程 | 重算或规则核对 | 常见错误与反馈线索 |
| --- | --- | --- |
| 双向拍卖 | 买 6、卖 9、平台 6、总计 21。二手平台验货后总计 16。 | 辨认费的去向和支付抵消。限价买单在未与卖价交叉时等待。 |
| SVB | 实付后现金 4、存款 57、待付 10、权益 10。 | 现金与存款应同扣，贷款与证券随账面估值进入权益。 |
| Schelling | 相同中央住户在 B 搬离前后比例为 40% 和 50%。 | 只数已占邻居。全图同类邻接率按无向边，轮次上限单列。 |
| 信息级联 | 赔率 1:2 乘 1/2 得 1:4，后验 20%。 | 两种信号都触发同一动作时，按公开策略判断行动的信息量。 |
| 公共物品 | 总贡献 30，罚款及施罚成本按本模型扣 8，小组净 90。 | 贡献回报收到后才计算施罚支出与受罚扣损。 |
| 公地 | 实际取出 30 后余 120，按容量 240 再生 33，下期 153。 | 用取用后存量作再生计算，管护缴费按群体内部转移。 |
| 柠檬市场 | 价值 6，成本 5，核验耗用 0.5 时净剩余 0.5。 | 愿售状态、退出与实际交割分别由对应事件确认。 |
| 学校匹配 | 学生偏好 B 胜过现去处，且优先序可替换 B 校学生，构成阻挡对。 | 先声明用真实还是申报偏好，按优先序和容量核对。 |
| 啤酒游戏 | 在库 12＋已订未到 9−积压 5＝16。 | 把订货与运输、到货和净库存分开。零方差分母留空。 |
| 碳市场 | 两吨增量分别 1、3，减排成本合计 4。 | 初始免费分配改变净支付，成本结论依赖固定总量和无摩擦假设。 |
| 闪电崩盘 | 买盘 18−成交 4−撤单 7＋新增 2＝9。 | 最后价格来自上笔实际成交，空簿价差留缺失。 |
| GameStop | 借 12、买回 5、实际还 4，欠 8。 | 话题触达、交易与归还由不同事件确认。 |

复算入口为 [机制参考用例](../../tests/contracts/test_learning_content.py)。作者 CLI 验证先修、版本、活动关系、来源、参考答案和评估器。v3 选择题的配置答案位置分布为 27/14/15，展示按档案和变式稳定打乱。顺序题按动作 ID 存储。课堂效果需要真实学生数据。

本轮 120 道可执行题，包括 36 道独立应用题、36 道迁移题、36 道复习题及 12 道课内练习。
