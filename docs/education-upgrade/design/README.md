## 设计决定

### 学习首页

保留既有产品壳，在继续任务旁仅给一项短复习与一项下一课。推荐明确原因。主线活动进度与能力证据分别呈现，不使用总掌握百分比。概念档案连接尝试与解释，允许学生回看状态依据。自由实验位于次级导航。

示例状态只为展示布局；4/7 不是测量值，也不是模拟数据。

### 学习活动

中央使用明确标注的人工教学例题：现金 8、证券账面价值 92、存款负债 90、提款要求 15，单位为代币；它们不对应 SVB 的真实财务。题设禁止此刻出售证券或借款，帮助学生先区分现金缺口和净资产。答案未预填。

左侧保留七阶段，当前阶段可含必要与可选活动。右侧只突出一个主提交动作，并明确当前已查看提示，本次属于辅助练习。下方解释卡作为后续草稿预览，避免同时要求长篇写作。主张、证据、机制和边界分栏；引用可核对与机制正确分开检查。

## 渲染与验证

使用本地 Inkscape 将 SVG 渲染为 PNG，并通过 `view_image` 实际查看两张最终文件。已修正当前渲染器不支持阴影滤镜而导致的卡片底色丢失；移除滤镜后再次渲染和查看。中文可读，未观察到遮挡、溢出或缺字；七阶段完整可见。

以上仅验证这两张静态设计板。它不等于浏览器响应式、键盘、读屏或产品端到端验收。

## 最终状态文案对齐

主能力状态统一为“未尝试 / 练习中 / 有独立应用证据”。当前首页示例使用后两种；“曾使用提示”和“独立应用尚待验证”只作为说明。“待复习”与“迁移待练”是独立标签，不覆盖或清除已有独立证据。

此次对齐后已重新渲染和实际查看两张 PNG，新的并列标签没有遮挡或溢出。复制到最终交付时请使用本目录最新 SVG/PNG。

## 七阶段与技术合同对齐

活动板最终采用：01 问题与角色（intro）、02 预测行为（predict）、03 选择行动（bid）、04 观察演化（observe）、05 解释涌现（explain）、06 反事实比较（compare）、07 总结迁移（notebook）。账表判断是 intro 内的当前子活动；没有新建“认识主体”phase，也没有省略行动阶段。阶段标签修正后重新渲染并实际查看活动 PNG，左侧七阶段及必要/可选子活动均可读。
