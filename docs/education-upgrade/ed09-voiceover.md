# ED09 · macOS VoiceOver 字幕实测

rc.3 的 Safari、Chrome 字幕补验见 [收尾验收](closeout.md) 和 [rc.3 字幕记录](ed09-rc3-voiceover.json)。以下是 rc.2 历史记录。

2026-11-18，使用 macOS 27.0（26A428）ARM64、系统 VoiceOver 10 和 Chrome 158.0.8127.36，执行 `1.1.0-rc.2` 解包的本地课堂。浏览器与 SQLite 临时隔离，测试页请求限定在回环地址。11 项观察均取得系统旁白字幕。

| 路径 | 动作与字幕 |
|---|---|
| 双向拍卖 | 聚焦「卖方剩余（代币）」，按 Tab 读到「平台收入（代币）」。回车提交错答读到「再核对这一步」。进入例题读到二级标题「看一个完整例题」，返回读到二级标题「练习」。 |
| 硅谷银行挤兑 | 读到「现金（资金单位）」。回车提交错答读到「再核对这一步」。 |
| Schelling 居住隔离 | 读到「已占邻居数（人）」。回车提交错答读到「再核对这一步」。 |
| 教学展示 | 聚焦入口读到「链接，打开隔离展示课堂」。首次课堂内导航未捕获标题，随后在独立标签切换并刷新教学页，字幕显示「双向拍卖教学活动」。 |

逐项动作、字幕摘录和原图 SHA-256 见 [结构化记录](ed09-voiceover.json)。原始截图保存在工作区的 `output/playwright/ed09-voiceover/`。三课错答触发的是同一句反馈，原图分别按各自提交事件采集。

## 采集方式

临时开启系统旁白。用 Playwright 在已构建的本地课堂运行规则实验，执行字段聚焦、Tab 和回车。用 Screenshot 技能枚举系统旁白窗口，再按窗口 ID 捕获字幕浮层。早期试采遇到系统切换前台，已清理该次临时帧。正式采集核对独立 Chrome 进程在前台，只保留系统字幕窗原图。用 OCR 定位关键帧，再逐张查看确认。拍卖例题往返另断言浏览器实际焦点。

旁白已恢复关闭。此轮覆盖 Chrome 加 VoiceOver 的指定通路。[Safari 补验](ed09-safari.md#safari-加-voiceover-字幕补验) 已确认教学展示的两项字幕，课堂字段和反馈播报仍待确认。实体移动端、TalkBack 与 NVDA 的读屏组合仍待验。
