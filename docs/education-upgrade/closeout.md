## 本轮的执行场景

**学习者。** 在拍卖、SVB、Schelling 用独立档案提交规定错答，能找到当前反馈并继续读字段解释。看例题返回后仍可定位原题。重答、求助和首次答题保留各自证据分类。注入保存失败时仍可核对输入并重试。

**教师。** 从双向拍卖教学活动进入隔离展示，再返回个人课堂。显示当前课名与展示入口，个人作答、暴露和原预测通过原档案恢复。

**发布验收。** 解包后用临时 SQLite 和独立浏览器档案执行。源资料与规则例题保留原数据身份。最终收据写明当轮成功、失败和未取得环境的项。真实课堂可以沿同一动作表记录完成、中断、提示和恢复，学习效果另用真实独立作答评价。

交付入口为 [发布验收](release-acceptance.md) 和 [本机启动指南](../../STUDENT_LAB.md)。按本机结果更新本表的签收记录。

## 外部验收条件

本机未发现可操作的实体手机、平板、Android 或 Windows 读屏环境。用上方三旗舰与教师场景在实际目标设备记录系统、浏览器、读屏版本、动作和朗读。WebKit 模拟触控作为浏览器覆盖。

课堂效果需要实际参与者、授权和真实作答。可使用三旗舰情境，记录完成与中断，再用其独立变式和迁移题核对表现。演示、测试和辅助作答沿原合同标记。真实供应商实跑需要明确授权、可用配置及预算，当前本地验收使用规则和测试传输。
