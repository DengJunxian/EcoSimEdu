# 浏览器学习状态

课程活动沿用原七阶段。课堂中的运行、回放时点、揭示上限和固定主体继续由原课堂管理。v3 阶段内活动使用课程版本与稳定活动 ID。补救一次进入一个例题，返回原题。可跳过学习题，跳过不产生尝试或能力证据。

`ecosimedu-learning` 的尝试、当前活动和反馈暴露在同一提交事务写入。提示与例题在记录暴露后展示。帮助记录写入失败时，课堂仍提供帮助，并尽可能在浏览器标记暴露未知。明确的规则任务首次无帮助达标才进入独立证据，迁移单独派生。

旧课堂使用现有解析器。系统按旧 key 和内容 SHA-256 备份原值，记录活动位置和暴露未知，同一个快照重复读取时复用迁移收据。旧笔记和运行继续由原入口打开，旧答案不会成为新尝试。


实验笔记页提供统一备份与合并恢复。备份含作答、历史版本、活动、本地复习、解释卡、实验卡、暴露及迁移备份。恢复核对当前题目版本、题目字段和规则评价，同 ID 同内容去重，异内容事务回滚。缺少相应课件的作答原样留档。未提交的帮助暴露随备份单独恢复。已有笔记恢复入口继续核对原运行；打开解释卡时复核运行引用，原库暂不可用时可保留文字。SQLite 数据库需另行备份。

拍卖结算、SVB 权益和 Schelling 九格表单会追加练习记录。原表单的反馈历史记为暴露未知或重复。运行计算附当前可见事件的身份；九格编写例题以项目教学数据为上下文。个人作答与复习可从备份入口清理，解释卡、实验、原笔记和提示暴露继续保留。
