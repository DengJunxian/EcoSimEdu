# 学生与教师使用指南

打开 [学生实验室](http://127.0.0.1:8776/)。首次安装和启动见[本机启动](../STUDENT_LAB.md)。基础课在本机运行，浏览器和服务可以断开外网。

使用键盘时，打开页面后按 Tab 到「跳到主要内容」，按回车进入页面内容。回放时可用方向键移动滑块。打开成交、原报价或 SVB 来源事件后，课堂会暂停播放并聚焦到目标事件的滑块。

## 做一次双向拍卖

1. 从[案例库](http://127.0.0.1:8776/cases)打开「双向拍卖」，进入交易大厅。以买家 B01 的身份选择成交预测，填写开局限价，然后提交。可以选择「不确定」。
2. 在撮合回放中按「下一步」或「播放至成交」。选成交点，查看买单、卖单、在簿顺序和成交价，将这笔成交引用到笔记。B01 未成交时可在收盘查看撤单并引用。
3. 收盘后核对买卖两方的剩余和平台费用。分别生成需求上移和交易收费对照，用同一个进度控件查看共同观察点。
4. 在实验笔记写下机制、证据成立的条件和下一问。导出 Markdown 可读版，导出 JSON 原始记录可用于恢复。

十二门课都可从案例详情进入新版课堂或原版课堂。社区地图支持方向键和按行列选格，图表可展开数据表。固定主体后可推进时间并跟踪该主体的余额、位置或行动。参数对照独立于课堂进度，从开局计算两侧运行。

「实验笔记」列出此浏览器的课堂进度、笔记和引用。打开原始事件可回到对应运行，旧版「我的实验」也保留原入口。离线学习助手使用课程材料和当前已揭示的运行证据回答。
## 边界实验

点课程首页的「边界实验」链接，再点「运行边界实验」。可播放轨迹、查看末条事件、导出 JSON。返回该入口后，可用「回放上次边界实验」重新打开此浏览器在本课最近一次保存的结果。双向拍卖还可以直接载入预计算回放。运行与回放使用原服务的数据库。

在双向拍卖「供需无交叠」中展开「查看边界供需曲线」，对照最高买方估值与最低卖方成本。成交量为 0，成交价显示「未定义」。可实现总剩余上界为 0 时，效率也显示「未定义」。

## 演示与高级实验

教师在「设置与帮助」启用教师模式，可下载当前课程的规则预设 JSON，在课程解释阶段查看参考答案。关闭教师模式后恢复普通学生界面。教师模式是本机展示控制，答案可从教学源码读取。

SVB 银行挤兑、信息级联、公共品和 GameStop 的行动阶段提供可选的「高级实验」。只有主动运行且服务配置可用时才会联系模型供应商。页面记录模型动作、回退、请求次数和估算成本。历史模型结果在关闭模型服务后也可回放。配置和账本说明见[开发指南](developer-guide.md)。

从顶部「模型实验」可以打开原版单角色实验或[多角色模型实验](http://127.0.0.1:8776/experiments/multi-role)。多角色页的「运行规则参考」断网可用。启用供应商并确认预算后，公共品、SVB、级联和 GameStop 的指定角色可通过模型提议动作，仍由经济规则完成结算。页面展示已提交时点、模型动作和规则回退。运行中可在结算边界暂停、继续或取消，并导出已提交记录。

## 保存与恢复

学习笔记存于浏览器。运行和高级实验预算台账存于服务端 SQLite。换设备、浏览器配置、主机名或端口前，逐课导出 JSON 原始记录，并用[备份命令](developer-guide.md#备份恢复与校验)保存数据库。

1. 用备份数据库启动本地服务。延续同一浏览器配置时，使用原来的主机名和端口。
2. 新版 JSON 在[实验笔记](http://127.0.0.1:8776/notes)的「恢复新版笔记」导入。服务会核对引用对应的课程、运行和原始证据。重复导入同一份备份会保留现有记录。导入另一份同课记录需要使用另一浏览器配置。
3. 原版 JSON 从该课程的原版入口导入。原版运行与新版课堂兼容时，也可在新版课堂选择「用旧版基准运行继续」。这会沿用原运行 ID，原版进度仍可从原入口打开。
4. 如果提示缺少运行或版本不匹配，保留原 JSON 和 SQLite 备份。使用能读取该记录的课堂版本恢复；已保存的旧事件仍可用其原链接查看。
若页面无法打开，查看 [本机健康检查](http://127.0.0.1:8776/api/health)。确认打开的是启动命令中指定的端口。遇到浏览器存储失败时，可以继续实验并及时导出笔记。
