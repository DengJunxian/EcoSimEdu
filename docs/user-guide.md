# 学生与教师使用指南

打开 [学生实验室](http://127.0.0.1:8776/)。首次安装和启动见[本机启动](../STUDENT_LAB.md)。基础课在本机运行，浏览器和服务可以断开外网。

## 做一次双向拍卖

1. 从案例库进入「双向拍卖」，点击「开始实验」，选择预测。可以选择「不确定」。
2. 查看自己的估值并报价，运行实验。进入观察后，用「跳到下一笔成交」定位事件，选两笔成交作为证据。查看买卖双方的报价与成交价。
3. 揭示初始估值和成本，比较真实成交、双方剩余与配置效率。用已经给出的两组反事实观察改变条件后的结果。
4. 写完「观察」「机制解释」「成立条件」及「迁移」，完成并导出笔记。可转到柠檬市场，比较质量不可见时如何改变交易。

社区地图支持方向键，也可以展开「按行列选格」。图表下可展开成交价格表或指标数据表，用表内的事件按钮切换时间轴。

「我的实验」列出此浏览器的课程进度和可打开的已保存事件。从已保存运行可点「按事件序号查看」，直接跳到任意事件序号，查看原始字段，再打开关联快照。「概念」可按术语搜索。「收藏」保存在当前浏览器。「离线学习助手」可以解释课堂概念与当前运行的已知证据，引用会回到对应课程或事件。

## 边界实验

点课程首页的「边界实验」链接，再点「运行边界实验」。可播放轨迹、查看末条事件、导出 JSON。返回该入口后，可用「回放上次边界实验」重新打开此浏览器在本课最近一次保存的结果。双向拍卖还可以直接载入预计算回放。运行与回放使用原服务的数据库。

在双向拍卖「供需无交叠」中展开「查看边界供需曲线」，对照最高买方估值与最低卖方成本。成交量为 0，成交价显示「未定义」。可实现总剩余上界为 0 时，效率也显示「未定义」。

## 演示与高级实验

教师在「设置与帮助」启用教师模式，可下载当前课程的规则预设 JSON，在课程解释阶段查看参考答案。关闭教师模式后恢复普通学生界面。教师模式是本机展示控制，答案可从教学源码读取。

SVB 银行挤兑、信息级联、公共品和 GameStop 的行动阶段提供可选的「高级实验」。只有主动运行且服务配置可用时才会联系模型供应商。页面记录模型动作、回退、请求次数和估算成本。历史模型结果在关闭模型服务后也可回放。配置和账本说明见[开发指南](developer-guide.md)。

也可以从页面顶部打开「模型实验」，直接选择案例和学生行动。完成后对照的两列使用同一规则情景、种子和学生行动。可以导出对照 JSON，或从模型决策的事件链接查看完整轨迹。供应商失败时页面显示规则回退，仍可核对本地结算结果。

## 保存与恢复

学习笔记存于浏览器，实验和模型预算台账存于服务端 SQLite。清理浏览器、切换设备或更换 localhost 端口前，逐课导出学习笔记并备份 SQLite。恢复时先用备份库启动服务，再从课程导入同版本笔记。没有原运行的引用会提示不可用。「收藏」和教师模式随浏览器配置保存。

若页面无法打开，查看 [本机健康检查](http://127.0.0.1:8776/api/health)。确认打开的是启动命令中指定的端口。遇到浏览器存储失败时，可以继续实验并及时导出笔记。
