# RC10 模型实验台

课程页顶部新增「模型实验」。学生从服务端公布的四门课中选择案例和行动，可在同一页面启动高级模拟、对照期末指标、打开执行事件和导出对照。服务关闭时，实验台保留案例说明及返回课程入口，基础课仍可运行。桌面并列呈现设置和结果，窄屏按实验顺序排列。

完成的高级实验以 `GET /api/runs/{id}/rule-reference` 生成同课程版本、同机制参数、同初态、同种子和同学生行动的规则基准。模拟角色的模型动作由原有服务验证后交给规则引擎结算。对照包含规则基准和原运行的独立哈希，可导出 JSON。
