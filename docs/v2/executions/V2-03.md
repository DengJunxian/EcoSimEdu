# V2-03｜问题首页与教学工作台

从 `codex/ecosimedu-v2` 的 `feba0be355e33ee360d12979c39ac4d860d1db33` 开始。先完成渐进首页与双向拍卖，再把共用界面接到案例库、课程详情、实验笔记和原学生端首页。运行命令沿用 V2-02 的 `Lesson`、`Session` 及证据接口。

## 页面

| 入口 | 可操作成果 |
| --- | --- |
| `/explore/` | 问题标题和首课行动；有记录时显示继续学习。四条路径、十二课以及先修概念和原课堂链接。 |
| `/cases` 与 `/cases/{case_id}` | 问题成为案例卡主标题。搜索、难度、材料和路径筛选可组合，无匹配时可以清除筛选。详情把学生要做的选择和四阶入口放在一起，保留原课堂、收藏、先修概念、学完能做什么和资料来源。 |
| `/explore/?lesson=double_auction` | 先出价并预测，再观察主体。宏微联动以同一事件驱动画布、参与双方、个体透视和宏观数值。图旁的表格入口展开已揭示的事件表。手机的标签共用回放按钮和游标，价证与「下一步」按暂停流程可见。 |
| `/explore/?view=notes` 及原事件 | 使用共用标题、空态和证据面板。原解释、双侧引用及 V2-02 的版本与摘要核验继续可用。 |

[令牌](../../../content/student-theme.css)由两套学生端读取。[共用组件](../../../content/student-ui.tsx)提供 AppShell、Navigation、PageTitle、Breadcrumb、CaseCard、EvidenceCard、ProgressStepper、ActionPanel、MetricCard 和 InspectorPanel。[工作台](../../../frontend/src/Workbench.tsx)组织响应式视图，界面层通过原选择与定位命令更新同一个会话。模型规则、随机输入、版本和学习存储键沿用原实现。

## 实测

在 Chromium 与 WebKit 分别跑 320、390、768、1440px。通过案例库打开双向拍卖，报价 96，预测「不会成交」。在事件 4 暂停，真实配对为 B01 与 S02。成交价 96 由在簿单 O001 给出。用原生控件选择 S02、回查 O003，并从指标表定位事件 3 和 4，事件 5 在推进前保持不可见。随后进入同种子政策实验，基线与每方每件收费 6 的运行分别成交 6 件与 4 件。[工作台测试](../../../frontend/tests/workbench_browser.py)

两浏览器复测加载中、课堂资源失败和重新载入、损坏检查点保留、断网单步执行、模型服务未启用。窄屏通过键盘方向键与 End 切换标签，焦点可见。学生进入系统结果前不会提前看到曲线。检查四档页面没有非预期横向滚动，并验证减少动态效果时主体过渡时间为 0。跨日回到事件 4、保存解释与从笔记回查也通过 320px 复验。

| 检查 | 结果 |
| --- | --- |
| 两套生产构建与 Node | TypeScript、Vite 与 esbuild 通过，35 项 Node 通过。 |

| 旧模型对照 | 64 条实际轨迹、4,640 帧一致。 |
| 自动无障碍和人工核查 | axe 4.12.1 在四档宽度检查 24 个页面状态，最终 0 个自动违规。人工换算 axe 留待核查的 SVG 文本，首页至少 11.04∶1，拍卖个体标识至少 7.55∶1。Impeccable 源码检测返回空数组。 |

初次验收发现 esbuild 在共用文件所在目录使用了旧 JSX 转换，旧案例库无法渲染。为旧端构建明确使用自动 JSX 转换后，重新打开案例库。真实截图发现详情主按钮的字色被通用链接样式覆盖，已纠正层叠优先级。旧备份复验中把静态笔记空态调整成普通说明，导入结果继续由原状态区域播报。自动检查发现先修链接高度约 22px，调整至至少 32px 后复查四档首页。

## Skills

- **Impeccable** 读取产品语境、首课设计和教学设计板。按实际任务调整层级和窄屏路径，并检查真实截图、焦点、对比度和触控目标。设计板用于参考，验收图由运行中的产品实际截图。
- **Codebase Design** 将令牌和共用 UI 放在两端已有的同源内容层，通过原会话命令同步核心视图。用原模式和旧备份的浏览器测试检查这条接缝。
- **Playwright** 用 CLI 检查实际页面，再用仓库浏览器脚本复跑四档界面和完整课堂。验证使用独立浏览器档案、真实规则运行和本地测试库。

实体手机、配合原生读屏以及付费模型未纳入本轮验收。
