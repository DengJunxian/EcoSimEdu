# V2-04｜Emergence Microscope 双向证据追踪

从 `59fb4b5` 开始。三门旗舰的渐进课堂在第三阶开放「涌现显微镜」。数据由原浏览器规则运行提供，旧实验室沿用 `/api/emergence/runs/*`。两个入口保留各自已登记的运行身份和经济时钟。导出增加独立的 `ecosimedu.microscope/v1` 格式，旧学习记录、课堂作答、运行摘要和模型规则沿用原格式。

## 学生可用的操作

- 从主体卡查看该主体已揭示的行动，沿原事件定位订单、入队申请、到账或邻域变化。可在同一运行中沿信号返回来源，也可从来源追到已揭示的后续决策。
- 点宏观曲线或使用「从指标数值反查事件」定位同一个游标。显微镜展示数值前后、净变化和可以复算的算式。拍卖成交价首次出现时保留前值与净变化未定义。百分比差异用百分点。
- 显微镜把直接行动、指标核算、接收到的信号、规则触发和后续反馈各自标识。缺少关联或计算口径时显示「当前模型未提供这类证据」。观察视角、主体、事件、关系、指标和揭示范围共享一次会话，并随检查点恢复。
- 角色视角显示角色自己的观察，关闭系统曲线和其他主体的导航。两种视角下的拍卖引导都保留公开原始报价，并隐藏会暴露私人估值的个体剩余。现有完整复盘入口保留。外部旧 Trace 接收时复核运行 ID、摘要、焦点与可见前缀。
- 「导出当前显微镜证据」携带运行 ID、版本、结果摘要、原事件 ID、经济时点、揭示上限、关联指针、前后状态及可核对算式。SVB 的单笔现金用台账复算，主体账表标明观察到的轮末粒度。导出对象只含当前投影。

## 三条实际链

| 课 | 浏览器证据 |
| --- | --- |
| Schelling | 种子开局选 A001 迁入保留空格。事件 1 邻域记录包含 14 名受影响居民。同组占用邻接对从 529/1051 到 527/1051，显示的比例从 50.33% 到 50.14%。揭示到事件 11 后可正向定位 B062 的后续搬迁，再由该次搬迁前的邻居计数回到事件 1。 |
| SVB | 浏览器轮内事件 1/2 是 D01 的工资款申请，1/4 实付 19，银行现金由 100 变为 81。按实付记录回到实际入队申请，再从申请回到支付。刷新保留精确子事件。旧服务的支付关系另用原 `request_id` 回查实际申请，保持旧服务自己的事件序号和总支付。 |
| 双向拍卖 | 种子 1962、限价 96 的事件 4，O001 与 O003 成交，先在簿的 O001 给出 96 代币定价。累计成交量由 0 变为 1。事件 5 揭示后，显示 B03 的报价确实读取了该成交价。可用键盘或触摸回查，切入买方角色后隐藏其他主体视角。 |

向前索引可以在内存中提前建立，视图、交互和导出只接收揭示界内的记录。离线规则实验的原始合成数据在浏览器运行环境中可用。私有字段保护适用于引导页面、链接、导出及旧服务投影。

## 验证和性能

- 两套生产构建通过。39 项 Node 测试通过。Python 回归覆盖 462 项，包括原六课 Trace、跨端口学习备份、旧版证据核验和角色可见性。
- Chromium、WebKit 实跑三条机制链，覆盖 390px 与 1440px。在 390px 测试触摸定位订单，键盘定位事件和关系后核对焦点。通过浏览器辅助功能树核查三种视角及当前事件读法。在原体验回归中复测 320px 跨天续学及旧笔记回查。
- 与旧引擎比较 64 条确定性轨迹、4,640 帧。原撮合、申请结算、居民搬迁和其他课程数值保持一致。
- 按运行缓存事件索引，按主体定位已揭示前缀，按帧缓存邻接计数。图表数据在相同揭示范围内保持稳定，移动游标只更新标记。指标表每页最多呈现 24 行，搬迁区间每页最多 12 条。实测 340 人、118／162 个真实 Schelling 事件帧，并在 200 模型步、368 事件帧的闪崩运行上测试指标表分页。macOS ARM64、Node 的 800 次实际定位中，两组 P95 分别为 0.049 与 0.054 ms，计量范围是证据投影。浏览器日志另记录从键盘激活到联动游标可读的实际时间。[性能脚本](../../../frontend/tests/microscope_profile.mjs) · [性能记录](../../../output/playwright/v2-04/profile.json)

## Skills

- **Codebase Design** 以原 `Session`、事件契约和课堂命令连接视图，把查找及投影集中在 [microscope.ts](../../../frontend/src/microscope.ts)。旧端共用可见范围检查与缺失证据文案。
- **Analyze Data Quality** 分别核对原事件序号、轮内子事件、经济时点及主体 ID。实测双向来源、空值、现金守恒、可重算邻接对。保留数值未定义和模型未记录的关系。
- **Impeccable 与 Playwright** 复用原工作台视觉、焦点及窄屏规则；运行真实页面，检查焦点、触摸动作、前缀、导出和大运行分页。源检测返回空数组。

本轮性能样本为现有规则模型的真实事件与模型步。实体手机和原生读屏未纳入实测。
