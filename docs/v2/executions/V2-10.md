本轮以 V2-08 的 `495216d` 和同工作副本中已有的 V2-09 三门信息类课开发为起点。将三门信息类课的真实证据与隐私投影纳入回归。原工作区和历史运行库使用原有入口。V2-09 其余六门课的四阶路径依靠共用工作台，原七阶保留领域视图。

## 发布修复

1. 统一首页教师工作台、四阶复习，以及原入口兼容。教师可选课、生成预设、启停隔离展示、控制示范解的揭示并核对作品。教师查看复算两组运行并核对事件。演示作答及其帮助、答案和反馈曝光均使用演示范围，个人档案保存原记录。
2. 两标签保存从原始检查点核对。活动继续，冲突可提示载入最新版本。拍卖需求分支按实际费用记账。旧需求分支的指纹只用于读旧证据。
3. 共用行动链保留旧可访问按钮名称。原拍卖助手在运行证据载入时等待，随后按已揭示边界回答。
4. 打包要求两套构建。独立审查复核 README、环境依赖、API 与课程源的各自身份。

测试过程和样本见质量报告。真实学生试用尚无数据。本地发布范围见路线图的已知边界。

## 回归结果

- 新旧前端 TypeScript 构建通过，Node 51 项。Python 契约与机制 344 项、五组浏览器 E2E 共 118 项。受演示曝光和助手载入改动影响的活动、复核及导师再通过 9 项专项 E2E，完整档案在两引擎再次往返。
- 本轮两引擎、两宽度十二课共 48 条无外部请求路径。在 320、390、768、1440px 另测关键任务。三条旗舰闭环在两引擎各完成一次，覆盖辅助与首次区分、独立迁移、次日复习和原证据回查。
- 两引擎在隔离教师浏览器中生成教学预设、启停及单步演示、打开并收起示范解、作答、导入解释和拒绝改写摘要。演示前后个人档案一致，切到个人课堂完成同题仍记为首次无帮助。旧签名需求运行用三个真实种子重算，逐个匹配原版本摘要。
- 131 条配对路径、9,738 帧通过与 Python 逐帧比较。课件检查含 12 个案例、36 项学习目标、20 条来源、56 个数据资产校验和。供应商状态、凭证保护、预算与异常的专项契约 36 项计入 Python 契约总数。
- 发布归档和本地启动使用两套预构建资产。锁定的 14 个运行依赖在干净的 Python 3.12 环境使用本机缓存离线安装。

完整调试收据写入本机 `output/playwright/v2-10`。本轮初始回归暴露了共享行动链可访问名称、已有助手等待事件时的提交时机，以及演示曝光的隔离问题，修复后以同一断言复测。提供商受控测试未使用真实计费凭据。
