## 学生可以完成的任务

- 四阶课堂包含情境、预测、行动、观察、解释、反事实和迁移。十二门课各沿用三个已有的结果目标。原题目、变式、版本、评分器、完整例题和阶段位置复用。初次预测先保存，错答后可继续实验，也可按程度查看线索、比较方法和依据。
- 双向拍卖的预测核对从已揭示记录读取 B01 的成交或收盘，SVB 从已揭示的 D01 申请核对待付和现金的区别。其余十课的原预测按题干中的模型条件讲解。条件判断和实际结果各用自己的依据。
- 对照执行后，学生引用两组原事件，保存主张、规则、计算、配对差异和适用条件。解释卡提供独立练习入口。作答支持选择、排序、数值、证据定位和结构化短文本，反事实运行前保存方向预测。结构化短文本由原评估器核对字段，保留教师对论证内容的判断。
- 浏览器分别保存课堂位置、原预测、独立和辅助作答、已见帮助、自评、解释与导师建议。原评分规则仅将正确的无本题帮助的独立题记为该目标的独立应用证据。同题反复提交保留历史。首页可恢复课堂、打开到期复习、继续下一课或自由选课。
- 离线导师使用原有分层帮助与题目反馈，能从解释卡的本次实际来源提出追问。原实验室的可选在线导师继续通过服务端核对证据后生成建议。浏览器课堂的本地运行 ID 保留原来源，线上建议和作答评分各自留存。

## 档案与恢复

实验笔记接受原 IndexedDB 导出、四阶学习备份和完整档案。完整档案包含原作答、暴露、复习与作品，以及本地四阶进度、解释、自评和导师建议。没有成功写入 IndexedDB 的帮助，若有浏览器备用标记，会以暴露未知保守保存。原版入口与历史数据可继续读取。

导入先保存可下载的原档快照，再验证课程、作答、版本和格式。四阶区只增加空缺记录，有冲突时保留本地值。IndexedDB 使用原事务校验作答、迁移和活动。组合导入在事务提交前写入空缺本地键，失败时中止事务并尝试撤回本次新增的键。不同存储引擎不共享事务，若浏览器进程在提交时中断，已保存的导入前快照可用于恢复。历史运行的服务端 SQLite 数据继续通过原实验室保存，浏览器学习档案保留指向这些运行的引用。

## 实测

- B01 先报 96 并预测不会成交。规则引擎在事件 4 以 96 成交，显示与撮合条件有关的一级提示。学生完成同种子收费实验，成交由 6 件变 4 件，引用两边事件保存解释和追问。
- 练习题打开二级帮助后提交错答。新数值变式在未看过该题帮助或反馈时答对，记录为独立证据。同题再次答对记录为重复，复习仍由首次独立作答安排。关闭浏览器后，在同一档案推进本地日期并重新启动，从首页恢复第四阶和独立证据，打开到期复习并完成。另实跑选择、排序和跨课结构化解释。
- 在 Chrome 390px／1180px 和 WebKit 390px 完成完整验收。预测反馈、独立练习与复习共九份 axe 检查未发现违规。
- 独立档案导入原 IndexedDB 格式和完整档案。修改评分的档案被拒绝，原记录与失败前快照相同。模拟配额失败触发组合回滚，重试可恢复。帮助存储故障也保留未提交题目的保守暴露标记。保存的基线运行与事件按原摘要核验。
- 十二门课、36 个目标和 12 份 v3 学习包核对通过，另检查 20 条来源及 54 项数据资产校验和。新旧构建通过，42 项 Node 和 462 项 Python 回归通过。三门旗舰复跑证据、原笔记和旧版迁移备份，其余十课在两引擎、两视口执行离线四阶流程。
