## 实验设计

十二课各有明确的比较指标、单位、统计口径和经济时钟。期末累计量取最后记录中的累计字段。工作台支持峰值口径，当前发布的十二项主比较量使用期末水平或期末累计值。比例水平保留百分比，干预减基线以百分点计。

先选择处理和种子数，再提交预测。两组保留同一种子、同一参与者和入场动作。SVB 的现金替代同时增加可动用的现金并降低证券利率敞口。拍卖的需求处理明确改变买方估值，收费用另一项独立处理。图表与表格使用同一经济时点，两幅图共用纵轴。每侧保留自己的原事件序号。订单簿无成交时，成交量可为 0，最近成交价显示未定义。

十一门课支持课堂种子加两组预设种子。额外资产只包含原 Python 规则生成的参与者、随机输入或开局。课堂在浏览器内本地重跑两个规则分支。啤酒游戏的需求路径固定，执行一组。多种子表保留每对观测、差值、可比较数和失败数，并报告最小值、中位数和最大值。图片和分布均由模型结果计算。描述范围只适用于这些课堂仿真。
