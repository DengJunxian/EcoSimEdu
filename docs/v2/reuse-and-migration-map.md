## 逐课能力

每门课均可从新版 `/?lesson=案例ID` 进入四阶课并保存两组源证据解释，也可从原 `/learn/案例ID` 进入七阶课。各课原版有一条独立边界预设，可从 `/?case=案例ID&boundary=1` 进入。旧端的 `/emergence` 对十二课提供机制条目及指标口径，表中的「Trace」指另有服务端通用追踪与直接探究入口。每课均有 `/teach?case=案例ID`，提供打印、展示档案及教学预设。教师四维复核的实际任务为 SVB 与闪电崩盘的双来源作答。

原版 12 个 v3 包共 36 个目标，支持作答、复习、归档等旧端正式工作流。四阶本机解释和续学是独立记录。原版配对支持有界参数，并按实际经济时钟对齐。四阶表列的是各课已实现的一个重点处理。SVB、信息级联、公共品、GameStop 另有原端可选模型实验。可用条件按现行接口和预算反馈呈现。

## 模块去向

| 能力 | 决策与入口 | 迁移目标 | 回归锚点 |
| --- | --- | --- | --- |
| 课程导航 | 直接复用四条路径、稳定案例 ID、前置关系与概念。适配原路径页和课程详情文案。 | `frontend/src/curriculum.ts` 读共同课程清单，原路由继续可达。清单校验一致后，逐步停止分别维护同字段。 | A01、A02、A10 |
| 四阶教学状态 | 复用 `lesson.ts` reducer 和 `Studio.tsx`，保留拍卖、SVB 专用视图。 | 将可见回放投影、状态持久化和记录写入从视图交互中区分。保留现有四阶转换和暂停条件。 | A02、A03、A05、A06 |
| TS / Python 规则 | 直接复用浏览器规则、种子资产生成与 Python 完整实验。 | 网关将实际来源和能力公开给同一 UI。使用现有逐事件对照约束共有口径。 | A04、A08、A11 |
| 宏微观视图 | 保留 `MetricChart`、Inspector、旧显微镜、SVB 消息边、拍卖订单及访问表。 | 先适配可见 Trace 与实际事件，再复用视图组件。证据形状一致后收束重复列表。 | A05、A06、A12 |
| 反事实 | 复用 `Counterfactual`、`projection.py`、旧参数台。 | 统一成对观察行，保留两个原时点、共同根、合法处理与缺值；参数台仍服务高级实验。 | A07 |
| 正式作答与复习 | 直接复用 `activity-runtime`、`assessment`、`learner-repository`、`review-schedule`。 | 由原学习仓库维护尝试和帮助暴露。新展示按稳定活动 ID 接入，旧记录继续依原入口读取。 | A03、A09、A10 |
| 解释、来源与教师往返 | 复用 `Investigation` 和 `StudentNotes` 的四阶交互，复用 `transfer-record`、学习归档和教师展示。 | 先统一来源语义，再逐项接入口。个人、展示与教师导入记录各有身份。 | A03、A05、A09、A10 |
| 原导航与已发布链接 | 持有 `student-web/src/main.tsx`、FastAPI 路由及帮助文档的兼容入口。 | 有替代体验且历史样本回查通过后，旧首页重复入口可降为兼容导航。原业务 URL、ID 和缺失时的恢复反馈继续服务已保存链接。 | A01、A10、A12 |
| 模型实验和服务管理 | 保持 `/api/local-model`、`live.py` 和 `live_l2.py` 的服务端约束。 | 前端读能力和状态。能在明确人工授权下启动，教学模式继续使用本机规则。 | A04、A11 |

潜在淘汰项指重复呈现、重复登记及重复解析逻辑。开展前应根据 [ADR](architecture-adr.md) 验收同一功能的替代入口、历史链接和数据恢复。
