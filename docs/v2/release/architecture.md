# EcoSimEdu V2 统一架构

| 部件 | 当前职责与接口 |
| --- | --- |
| `frontend/` | Vite、React、TypeScript。提供 `/explore/`、四阶状态机、微观画布、ECharts 和语义数据表。运行按课延迟加载。回查以已揭示上限为边界。 |
| `student-web/` | 兼容七阶课堂和旧查询链接，承担教师预设与展示、双来源复核、旧记录归档、参数台和模型实验。与四阶前端复用原活动执行、复习和 IndexedDB。 |
| `services/simulation/` | FastAPI 在同一来源交付两套静态页面，提供规则运行、受控实时模式、原事件、运行导出和 SQLite 持久化。 |
| `cases/` 与 `content/` | 发布目录、来源及教学假设、学习目标和正式题包，生成版本化 CasePackage。组件共享路由、证据语义和领域视图片段。 |
| 原研究应用 | `app.py`、研究引擎、研究端的模型和配置。独立启动。 |

## 从课堂到原证据

`Lesson.run` 读取明确的种子、学生选择和合法制度参数。真实计算写出逐帧主体、指标和事件。阶段三的焦点由时点与原事件共同表示。模型算术用原始记录和前后数值核对。SVB 的轮次与子事件保留各自身份，Schelling 的邻域关系保留原搬迁记录。

`RunEnvelope` 包含引擎、案例和内容版本、种子、输入、来源和摘要。浏览器规则运行以自己的字符串 ID 标识。FastAPI 历史运行保留 UUID；预计算回放与在线模型按各自的来源和回执读取。解释及实验卡保存两侧独立的事件引用。模型跨引擎的逐帧一致性检查比较结果，不改写来源身份。

## 保存与隔离

四阶检查点、解释及辅助记录使用同源本地存储；正式活动、曝光、尝试和复习使用 IndexedDB。服务器运行在 SQLite。教师展示使用独立 demo 键及学习档案；作品查看在页面内复算，教师复核记录走专用导入导出。教师工作台的角色隔离面向本地教学。站点本身以回环地址运行。

模型密钥位于本机服务环境或进程会话。配置端点检查同源回环来路。运行、学习归档及价费回执使用公开元数据。高级模型不可用时，基础规则路由仍独立可用。
