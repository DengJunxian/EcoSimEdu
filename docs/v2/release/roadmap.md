# 已知边界与下一版本路线图

## 当前边界

- 本地档案依赖浏览器来源和本机运行库。教师展示使用本地角色隔离。多用户服务需要登录、授权及服务器档案能力。
- 三门旗舰具备四阶显微镜，三门信息类课程有领域画布，其余六课有领域回查面板。四阶公地对照采用统一取用限额。含执法成本的管护账户可在原七阶公地案例查看。
- 配对实验使用预设教学种子。啤酒游戏的需求路径固定，界面提供单组结果。课程中的主体和数值按教学规则生成。历史类课程的市场或银行事件用于背景定位。
- 教师作品查看支持已导出的 V2 解释作品，校验两侧运行。SVB 至闪电崩盘使用专用教师复核格式。两条原运行都可读时才接受查证与评分。缺少运行时保留原作答文件，回到含有原数据库的服务重新导入。旧作品可用原版本或兼容笔记入口回查。教师预设文件记录展示安排和原规则参数，由教师在演示课堂按需执行。
- 自动化浏览器覆盖、同源离线测试和真学生试用各有自己的验收证据。V2 最新实体设备旁白和实际外部供应商行为留作实机及真实计费环境证据。
