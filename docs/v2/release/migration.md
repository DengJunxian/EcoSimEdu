# 数据迁移与备份

同一主机名、协议、端口和浏览器档案可以读取原有本地记录。优先用保存时的地址启动统一版，保留原 SQLite 路径。换来源前先在旧档案导出，旧来源的数据继续作为原件保存。

| 要保留的内容 | 在旧环境操作 | 在新环境验证 |
| --- | --- | --- |
| 四阶检查点、原预测、解释、学习证据 | 在旧来源的 `?view=notes` 展开「备份与导入四阶学习」，导出完整学习档案。旧静态版缺少按钮时，在原地址提供新版静态构建后导出。 | 到 `/explore/?view=notes` 导入。选择一个课堂恢复原阶段，打开一份旧解释和两条来源。 |
| 原版正式作答、七阶进度与笔记 | 到原 `/notes` 分别导出作答记录和课内原始记录。原通用课的 JSON 从原课堂导出。 | 在对应入口恢复。查看一条首次答案、一次辅助尝试及原场景。 |
| 原 UUID Run、历史分享地址与证据 | 保留原服务及其 SQLite，或用本地备份工具得到完整副本。将运行导出作为可查验文件共同归档。 | 用原 `case/run/event/tick` 查询打开一个实际事件，核对源 ID、序号和摘要。 |
| V2 实验卡、解释作品、教师复核文件 | 从对应页面导出单个 JSON。 | 实验卡在同课「恢复本课实验卡」重算。解释作品在教师工作台核对。跨课复核使用 `/practice?review=svb-flash` 的专用格式。 |

导入会先生成可下载的当前档案快照。也可事先导出完整学习档案。同键同内容去重，同键冲突保留目标原记录并给出回执。校验失败时检查文件、版本和来源。缺少旧运行时保留原文件，在持有该运行库的本地服务查证。以备份副本演练后，再切换实际数据库地址。旧格式的提示和反馈曝光没有记录来源角色，按已有曝光保留。新演示曝光单独存放。
