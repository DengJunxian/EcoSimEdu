# 十二课教学验收表

每课从课程地图打开，提交开局决定、切到微观观察、核对真实模型事件，提交政策预测并运行配对。十二课皆可进入解释及正式练习。以下数值来自本轮浏览器或逐帧运行；教学练习的自编输入在作答界面另行标记。史料用于提供问题背景，表内比较使用相同课堂条件的规则运行。
