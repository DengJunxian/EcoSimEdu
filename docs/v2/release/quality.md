# V2 性能与无障碍报告

## 运行环境和任务

本地统一服务使用隔离 SQLite、关闭实际在线调用。浏览器运行于 macOS arm64，Node v26.0.0、Python 3.12.13、Playwright 1.65.2。浏览器用同源请求护栏验证离线课堂，服务端规则回归另行使用临时数据库。

| 学生或教师任务 | 起始状态与操作 | 可观察验收 |
| --- | --- | --- |
| 完成十二门规则课堂 | 新浏览器打开地图，完成选择、观察、对照并核对解释导出 | 课程实际运行、两侧原 ID、公开指标。Chrome 和 WebKit 共 48 条四阶路径，包含零成交分支检查。 |
| 三条新生闭环 | 三个空档案分别做拍卖、SVB 和居住隔离，保存解释、提交独立应用与迁移，再模拟次日 | 两引擎各三条路径，能从同一应用进入定向证据、写解释并完成新题复习。 |
| 教师 | 选居住隔离、导出 40 分钟预设、开启隔离展示、展示后按需打开示范解，导入学生解释作品 | 预设带合法条件，真实运行可播放、停止和单步。有效作品核对源 ID，摘要被改的作品被拒。演示提交一份独立题后，个人档案逐项相同。切回个人课堂，同一题的首次作答仍为独立证据。 |
| 返回续学 | 两标签打开同一拍卖课，一侧推进，另一侧在旧位置回退 | 陈旧保存显示冲突。载入最新进度后，可有意退回并持久保存。 |
| 导入与来源 | 完整档案、旧文件、两来源教师复核、原 URL 与实验卡 | 恢复保留首次数据与曝光，坏档拒绝，失败回滚，可从两组运行反查。旧需求分支的原摘要可识别。 |
| 模型异常 | 未配置、违反来路、一方预算不足、鉴权/输出错误和暂时不可用 | 规则入口仍可打开。测试凭证未写进浏览器或运行导出。受控模拟供应商测试预算与回退。 |

## 无障碍与布局

- 320px 检查首笔成交暂停，证据和下一步同屏，键盘任务和焦点恢复。
- 390px 检查十二课、实验档案、旧链接、显微镜和复习。768px 在 WebKit 检查三课闭环、教师作品和实验工作台。1440px 检查 Chrome 工作台、显微镜和宽屏图表证据。
- 使用 Playwright 的角色、可访问名称、焦点断言和 ARIA 快照。图表的证据表可用键盘定位，输入有标签，教师作品校验结果进入焦点。相关状态以文字播报。Axe 采样覆盖预测、独立练习、复习、教师作品和多种子实验。Impeccable 机械检查无发现。
- 可见范围按已揭示前缀核对。匹配在复盘前保留本角色志愿和已发生申请，其他人的完整偏好留到收尾。柠檬市场在交割前保留其他卖家私有保留价。信息级联在终场前遮罩他人抽样和未公开行动。专用角色视角保留原范围。
- 实测使用模拟视口和浏览器可访问树。V2 当前修改的实体设备与原生 VoiceOver 还需要验收。

## 性能样本

| 样本 | 规模 | 本机结果 |
| --- | --- | --- |
| 居住隔离，阈值 30% | 340 位住户，118 帧，400 次 Node 定位 | 首次索引和查询 24.99 ms，后续查询 p95 0.186 ms |
| 居住隔离，阈值 50% | 340 位住户，162 帧，400 次 Node 定位 | 首次索引和查询 5.32 ms，后续查询 p95 0.090 ms |
| 居住隔离浏览器 | 390、1440px，两引擎共 24 次定向操作 | 键盘到目标 DOM 17.18–77.92 ms |
| 闪电崩盘 | 40 个主体，368 帧，模型步 0–200 | 一次 Node 生成 683.39 ms。浏览器长表每页 24 条，四次键盘翻页到新行可见用时 10.43–134.08 ms。 |

样本来自实际模拟与浏览器操作。Node 计时包含当前次规则计算或查询，浏览器计时包含工具事件和 DOM 等待。Schelling 多种子分块约 508 kB（gzip 约 364 kB），由相应实验按需加载。当前样本不推断目标手机上的帧率。
