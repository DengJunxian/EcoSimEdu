# V2-06 · 双旗舰技能执行

- **pm-execution:test-scenarios** 为两课分别编排空白学生档案、起始决策、实际事件、反事实、独立迁移、原证据回查和备份恢复。用可执行断言检验不变、缺值和停止原因。[双课场景](../../../frontend/tests/flagships_browser.py)
- **Playwright** 用 CLI 查看本地教材的理论与实验来源。用 Chrome 和 WebKit 实测键盘、图表点击、订单簿、原事件和离线归档。隔离浏览器只允许同源静态 GET。
- **Impeccable** 延用现有工作台的焦点与色彩，把前后网格和订单簿布局放进对应视图。根据实际 320 像素截图，将邻居前后计数改为带表头的三列表格，并保持数值整组可读。
- **Analyze Data Quality** 将理论模型、学术实验与合成运行分开，复核原论文和原始规则。Schelling 逐格核验 8 条轨迹、561 帧，拍卖逐事件和账表核验 11 条轨迹、1,644 帧。旧浏览器运行指纹保持匹配。

新旧前端构建、42 项 Node 测试、462 项 Python 测试全部通过。已复验十二课的离线入口与学习路径、V2-05 的作答备份、旧版笔记和显微镜。两门旗舰课各覆盖三组浏览器与视口，12 份 axe 检查无违规。对桌面拍卖 20 个 SVG 标签从浏览器实际颜色补算对比度，最低 8.47:1。Impeccable 源码检查返回空数组。实体手机和原生旁白未在本轮复测。
