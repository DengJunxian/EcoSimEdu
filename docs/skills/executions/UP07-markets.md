# UP07 · 碳市场、闪崩与 GameStop

- **A · 发现。** 核对项目 AGENTS、UP07 九课迁移规格、审查中的三个领域任务和模型实现。碳市场使用整数边际成本、登记簿和缴回。两门证券市场课程共享原撮合、真实订单和结算事件。课堂中的价格、动机、股数和时间来自模型。沿用案例既有史料出处。
- **B · 选择。** 使用 Impeccable 4.8.0 的 Operate 与 craft floor，按当前可见状态组织账本、深度阶梯和话题记录。使用本机 Playwright 和仓库现有 Chrome 验证框架。按两份 anti-defensive-writing 规范保留等结果、无成交、无借券和无新价格的机制边界。
- **C · 执行。** 碳市场以每吨成本核算、企业筛选和配额编号串起发行、结算与缴回。闪崩从深度和累计量的前后值回查撤单及原委托，暂停显示待执行量。GameStop 从来源事件回查话题和触达者，再用实际成交目的和交还义务对账。三门课各发布七阶段内容、一项可核对预测和三项分支反馈。 [碳市场课件](../../../cases/carbon_market/lesson-v2.json) [闪崩课件](../../../cases/flash_crash/lesson-v2.json) [GameStop 课件](../../../cases/gamestop/lesson-v2.json) [领域画布](../../../student-web/src/cases/markets/panels.tsx)
- **D · 交接。** 各课使用原有动作、状态和证据编号。公共课堂统一实现时钟、预设对照和笔记，领域视图选择可见事件与参与者，不读取当前游标之后的事件。碳市场采用制度相位，证券课采用模型步或轮次。
- **E · 验证。** 三项新增机制回归连同现有碳市场及撮合用例共 15 项通过。基准与免费分配对照的减排总成本均为 1,318.5，转移量为 14 和 10 张。闪崩撤单降低深度，成交量和最近成交价格维持原值。GameStop 的基准与取消社交权重组均触达 5 人，关注买量分别为 18、0 股，基准还券后的义务为 8 股。边界测试覆盖零配额、程序暂停至结束和无可借股票。Impeccable 检查返回空结果。 [机制用例](../../../tests/mechanisms/test_market_classroom_evidence.py) [浏览器用例](../../../tests/e2e/test_market_classroom.py)

Chrome 领域回归 3 项通过，分别覆盖 320、768、1440 像素的键盘输入、没有未来事件的开局、实际事件追踪、错误判断反馈、证据引用和页面无横向溢出。另用拦截外部请求的 390 像素独立浏览器走查三课七阶段、全部对照、核对证据、Markdown 导出与刷新恢复。三课末点分别显示阶段 3、模型步 200、模型轮次 10，两侧的最终快照均保有原事件键。截图保存在本机 output/playwright。
