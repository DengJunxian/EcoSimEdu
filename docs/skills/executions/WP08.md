# WP08 技能与执行证据

使用已安装的 OpenAI Docs 与 OpenAI API Key 技能，核对运行进程的凭证状态、官方模型 ID、Responses 严格结构化输出、计费和服务端环境边界。用户此前指定了供应商与预算。验证不创建密钥，凭证在本地运行进程中使用，仓库和浏览器中无密钥。DeepSeek 单独核对官方消息格式与不同计费口径。

按项目计划分三组独立接入四个角色动作范围和离线教学检索。主线统一供应商、预算、取消、效果与回执接口。四个钩子复用现有领域结算，分别用选择相反的动作确认能引起规则允许的响应。应用已读 anti-defensive-writing 处理课程及技术说明，保留真实请求中两门课与默认动作相同的结果。沿用 Impeccable 的界面约束展示真实、回退、取消和未知费用。

[验收报告](../../audit/wp08-verification.md)区分真实供应商结果、受控协议/状态测试和浏览器重放。独立复核从 SQLite 复算真实回执，并发现后续补测的取消与提交竞态、旧状态恢复、非回环防护和刷新恢复问题。
