- **Impeccable** 使用 `audit.md` 的键盘、标签、焦点与状态反馈检查，复跑源码检测器并在原生 Safari 对照实际呈现。学生端与课程内容沿用 rc.2。

- **原生界面与系统旁白** Safari WebDriver 远程自动化未开启，使用 Computer Use 操作无痕窗口并读取其可访问性状态。系统旁白已按授权临时启动并恢复原状态，字幕窗口无法读取。 [Safari 走查证据](../../education-upgrade/ed09-safari.md)

## macOS VoiceOver 字幕补验

- **Screenshot** 读取本机 `screenshot/SKILL.md`，用其 macOS 权限检查器确认既有录屏权限，按窗口 ID 只截取旁白字幕浮层。正式采集需确认独立 Chrome 进程在前台。
- **Playwright** 复用三旗舰课堂的规则运行和作答路径，在有头 Chrome 中触发原生可访问性事件，并核对 Tab 和标题焦点。用系统字幕截图验证读屏输出。
- **Computer Use** 临时开启旁白并恢复关闭。保留 11 张逐项核对的字幕原图及 SHA-256。 [实测与边界](../../education-upgrade/ed09-voiceover.md)

Safari 组合复测中，Computer Use 完成无痕课堂准备和规则运行，Screenshot 的窗口枚举确认独立旁白浮层。前台检查未命中 Safari 测试窗口，故未保留截图或记为读屏通过。 [Safari 复测记录](../../education-upgrade/ed09-safari.md)

获准激活 Safari 后，用 Computer Use 在无痕课堂按键作答并核对例题焦点。Screenshot 在捕获前后校验同一 Safari 测试窗口位于前台，保留 2 张确认项与 3 张部分证据原图。 [Safari 字幕记录](../../education-upgrade/ed09-safari-voiceover.json)
