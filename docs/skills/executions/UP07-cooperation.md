# UP07 · 信息级联、公共品和公地

- **A · 发现。** 对照 UP07 提示、现有三课模型说明、v1 运行与共享场景合同。核对第 3 位策略、P1 首轮贡献及 F01 首期计划三个可控行动，梳理公开信息、规则衍生后验、同步结算和监测账务的粒度。
- **B · 选择。** 沿用 Impeccable 4.8.0 的 Operate 与 craft floor，以原主题呈现可键盘操作的顺序链、公共池流量条与水域存量变化。使用 Playwright 本机 Chrome 校验真实运行及焦点。课程中文沿用两份 anti-defensive-writing 指南核对证据与适用范围。科学口径直接从模型函数与实际序列复算。
- **C · 执行。** 信息级联提供第三位私信号与当时可见的公开行动、动作似然和个人／公共后验。共享投影在结束前遮蔽其他人的抽样及答案。公共品按真实轮次先显示四笔贡献，再显示施罚、受罚和净收益。公地按真实期次先取用、后再生，同时区分扣缴转移和监测消耗。各课发布七场景、预测、差异反馈和证据要求，保留现有情景与动作。 [案例画布](../../../student-web/src/cases/cooperation/panels.tsx) [开局与可见性](../../../services/simulation/cooperation_view.py)
- **D · 交接。** 共享课堂负责路由、场景推进、统一播放、配对与笔记。本批提供各案事件选择器、展示投影和真实可引用的运行序号。公共品后续轮次仍按原规则推进，学生行动口径是 P1 首轮投入。
- **E · 核对。** 三课合同和模型测试合计 17 项通过。信息级联种子 3 的第三位私信号为 A，前两位公开选择 B，公共 A 箱后验是 20%；第三位在两种私信号下均选 B，行动似然均为 1。公共品种子 2000 的基准累计贡献 379、群体净收益 1027.4；低成本组累计贡献 405、群体净收益 963。公地零存量边界所有再生均为零；社区监测组逐期验证扣缴余额和净成本。Impeccable 检测返回空数组。Chrome 在 390、768、320 px 分别覆盖信息遮蔽、贡献与结算的时间先后、后续再生期与资源平衡的键盘操作及证据引用，3 项通过，均阻断外部网络。 [浏览器用例](../../../tests/e2e/test_cooperation_classroom.py) [领域契约](../../../tests/contracts/test_cooperation_visibility.py)

三课的证据引用、课堂保存、两臂配对和最终路径验收归共享 UP07 记录。教学效果和屏幕阅读器实测属于独立验证。
