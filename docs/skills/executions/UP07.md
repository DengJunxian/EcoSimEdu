# UP07 · 十二课新版课堂

- **A/B 发现与选择。** 核对本机数据质量、Impeccable、Playwright、两份 anti-defensive-writing 指南和既有教学验证。按真实动作、经济时钟、事件和可见信息选择不同画布。历史课沿用核对过的来源和教学模型身份。
- **C 执行。** 九课采用共同的七场景骨架，每课测试决策前预测、课中证据、错误分支、预设比较和可复核笔记。信息级联的引导和提前复盘对其他私信号遮罩。柠檬市场保留按信息制度显示的质量，直到交割才揭示明细。各课有原版入口和原边界实验。
- **D 协同。** 分三组独立核对并交付画布与内容，中央维护场景校验、选择器、路由、存储和对照。客户端按课堂加载领域渲染器。 [合作与信息三课](UP07-cooperation.md) · [市场配置与供应链三课](UP07-allocation.md) · [配额和市场运行三课](UP07-markets.md)
- **E 验证。** 九课分别走完从决策到对照、引用、记事和刷新的 Chrome 路径，阻断外网。领域回归另核对原始关系、键盘、零变化和缺事件，例如安全志愿没有本人被拒绝、暂停期间无新成交不更新最近成交价、公地零存量没有再生。 [七场景回归](../../../tests/e2e/test_course_upgrade.py)
