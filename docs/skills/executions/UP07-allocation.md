# UP07 · 质量、席位与在途订单

- **A · 发现**。核对柠檬市场、学校匹配和啤酒游戏的发布课程、行动域、机制、测试、边界配置与事件字段。三门课继续沿用原来源登记和原规则引擎。
- **B · 选择**。阅读实际宿主 Impeccable 4.8.0 的 Operate 与 craft floor，沿共享工作台使用纸白与深绿、键盘操作和明示缺值。用课程既有模型测试校对反馈的事实基础，用两份 anti-defensive-writing 说明写出成立条件与可复查动作。Playwright 在生产服务操作。
- **C · 执行**。三课各发布七个 Scene。柠檬市场按买方当期可见的单件信息遮罩，显示挂牌分布、退出名单、愿售与真实交割。学校匹配可固定申请人、按席位和优先序追查拒绝来源，再分两种偏好查阻挡对。啤酒游戏对齐零售下单、批发收到订单与实际运输周，按批次跳回发货事件，从库存位置拆出实物在途和待发。 [课程界面](../../../student-web/src/cases/allocation/panels.tsx)
- **D · 交接**。三个领域界面接入共享的 Scene、回放、对照、笔记和证据合同。域选择器分别绑定真实报价退出名单、S01 拒绝参与者和零售期末积压。学生可更换开局挂牌、志愿或第 5 周订单并从开局运行。啤酒游戏其余周数继续由原订货规则执行。
- **E · 验证**。原机制 16 项通过。新增生产 API 3 项覆盖每课基准、对照及边界，认证费 100 时没有认证、A 校 0 席时无人分配到 A、恒定需求时工厂方差比缺失。三门新版在 320、768、1440 px 的领域路径实测，使用键盘推进并回查来源，浏览器请求限制在本地。Impeccable 检测返回空数组。 [契约回归](../../../tests/contracts/test_allocation_classroom.py) · [浏览器回归](../../../tests/e2e/test_allocation_classrooms.py)

默认挂牌下，柠檬市场首轮混合报价为 3.6，12 件退出，交割仍是 0。学校匹配基准的真实申报路径是先申请 A、收到拒绝，再申请 B。啤酒游戏选择 20 件时，第 5 周实际到货 4 件，第 6 周批发确认收到 20 件订单。数据取自课堂当前运行。

本轮覆盖第 5 周的真实学生订货。逐周参与式订货仍依赖可继续的动作合同。
