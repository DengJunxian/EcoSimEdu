## 合同与验证记录

- 保持原 `POST /api/tutor` 用法。加入 `scene` 时，配合可选的 `actor`、`tick`、`reveal_until`、`prediction`、`evidence` 和 `hint_level` 调用任务导师。响应含 `intent`、`hint_level`、`claim`、`evidence_ids`、`next_action`、`unsupported_scope` 和可操作引用。保存记录可以提供同一运行的事件引用，实际数字仍从服务端投影读取。 [入口](../../../services/simulation/api.py) [回答路由](../../../services/simulation/task_tutor.py) [提示资产](../../../services/simulation/tutor_hints.py)
- 四个原开放问题及两个教学走查题获得各自的三级提示。独立问法中，SVB 事件 9 使用本次运行的现金 0、待付 107、净资产 155，并对固定 D16 定位个人待付 38。Schelling 的入场问题返回预测提示且无后续事件。同价拍卖问题使用规则和公开成交身份核对步骤。覆盖未到达事件、跨运行、缺失主体、私人成本、错误前提、替换数字及无关问题。 [API 合同](../../../tests/contracts/test_task_tutor.py)
- Chromium 以 390 和 1440 像素在双向拍卖中依次操作选级、提交报价、查询未来事件、回放后读取真实价格和按 Enter 返回事件 4。浏览器拦截外部请求，验证焦点与横向溢出。 [浏览器用例](../../../tests/e2e/test_task_tutor_browser.py)
- 可选在线组织解释需服务端同时启用 `CIVITAS_TUTOR_ONLINE_ENABLED=1`、`CIVITAS_LIVE_ENABLED=1` 和已配置供应商。只对本地请求、已核实的公开运行观察提供按钮。服务端发审核后的结论、检查步骤和证据 ID，由模型选择两种呈现顺序。账目文字和数值从本地重新渲染。尝试使用独立请求 ID 去重，并计入共享币种费用上限。模拟超时、非法动作、替换数字和预算不足均使用离线回复。供应商端网络、计价和质量尚未经真实请求验证。 [在线适配器](../../../services/simulation/tutor_online.py)
