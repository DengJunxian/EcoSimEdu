# WP06A 技能与执行证据

采用两份已读 anti-defensive-writing（版本见 [WP02](WP02.md)）组织模型条件、学生任务与证据。五课均保存精确主张、来源支持范围和规则特定的等值或零结果。各个领域实现独立，研究与建模采用固定种子、配对干预、手算边界及不变量复算。技能审计参数与历史背景仅使用真实代码、数据和原始资料。

采用原有 analyze-data-quality 粒度和引用一致性方法（版本见 [WP00](WP00.md)）。[目录校验器](../../../scripts/check_lesson_catalog.py)重新计算 18 组运行，检查字段、刻度、证据数量、成对生成根和结果摘要；各案规则的领域约束由单独机制测试核对。各案配置和模型位于 cases/，测试在 tests/mechanisms/。

Impeccable 4.8.0（版本见 [WP03](WP03.md)）沿用已有页面方向，应用焦点可达、颜色外形双编码、窄屏指标全览和缺值显示，使用浏览器截图、机械检测与独立走查。Python Playwright 驱动真实 Chrome，在 1440 和 390 像素验证五门新增课。已有双向拍卖继续执行四档回归。

WP06A 衔接数据为 cases/catalog.json、统一事件 Schema 和每课实际绑定的模型。各课共享课程壳与存储，角色与关系语义由各自模型记录。公共品、资源、储户、报价和空间迁居分别采用领域规则。

## WP06B 技能与执行证据

继续使用原始来源核验、两份 anti-defensive-writing 与粒度/引用一致性检查。新增模型各自通过手算、守恒或算法不变量的专项验证，并以共享课程契约接入。Impeccable 沿用既有界面，补齐窄屏同步对照、具备来源的主体关系和空值显示。真实 Chrome 对所有课程执行断外网学习。

[本轮验收](../../audit/m3-verification.md)登记各课程规则、边界、可复跑数据与结果。测试工作分为三个领域边界并行开发，主线统一审查课程、原始机制、跨视图及 API。

## RC9 边界实验

延续 Impeccable 的现有布局和标签，小屏走查集中在入口、事件时间轴、缺值和导出。使用 Python Playwright 的真实 Chrome 本地通路，在十二课分别打开边界、推进和定位事件、刷新并回放、下载后与机制收据核对。用两份 anti-defensive-writing 组织[验收记录](../../release/rc9-verification.md)，保留零值、未定义和模型条件。
