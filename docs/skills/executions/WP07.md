# WP07 已交付部分

保留 Impeccable 的信息层级和可访问性约束，并复用数据质量粒度与主键检查。以运行 ID 和事件序号联动指标、快照、动作与主体。现有交易仍显示真实订单指针，Schelling 使用网格与可键盘访问的格子，其他课程以可读关系和角色事实列表表达实际记录。缺值显示为空，折线段在缺值断开。

同一运行的事件链接可以恢复本地观测点。API 返回当前事件、前后快照和可用订单指针，可由契约测试独立核对。同种子与同学生动作的反事实保留共同生成根。若 SVB 的初始资产组成或网络发生变化，单独提示实际初态变化。M2 时点的独立时钟对齐和抽样在下方 M3 扩展中实现。

## M3 扩展

同步对照使用已记录的阶段、轮次或周，按同一观察点并排展示。两组各自结束时的记录单独显示。缺失观察点不生成插值，每个有效点保留可跳转的原始事件。实际干预参数与共同生成根分开显示。主体交互使用受限关系图与完整列表，方向和事件来源一并保留。指标端点支持保留边界、区间极值和缺失标志的抽样。配对条件、不同事件序号同轮对齐和源点映射有独立契约测试。

当前规模以十二课本地模型为验收单位。增量快照持久化、长轨迹性能门槛和完整 WP07 验收仍是后续工作。

## RC3 扩展

保持快照入口，另建按原始事件序号定位的只读入口。沿用 Playwright 与 Impeccable 的交互及可访问性方法，验证关联快照、缺失、越界和旧链接。[事件定位验收](../../release/rc3-verification.md)
