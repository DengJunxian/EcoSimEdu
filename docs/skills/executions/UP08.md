# UP08 · 参数与可复算对照

- **A/B 发现与选择。** 复用经确认的 data-analytics:analyze-data-quality 1.2.0、codebase-design、Impeccable 和 Playwright。比对各模型原参数入口、初始化和配对轮次，适用参数用规则表限制。
- **C 执行。** [参数注册表](../../../services/simulation/parameter_specs.py)发布十二课离散取值、单位、模型路径与约束。新增 v2 请求保留有效参数、种子计划和行动序列。配对共享种子、学生选择和生成根，记录两组实际初态和处理差异。页面支持真实同步事件及主体状态、先出现的可比指标差异、缺侧状态和 JSON 导出。
- **D 协同。** 课程机制核对由三个领域批次分别交接，参数验证与配对统一维护。两种 Schelling 初态使用相同居民、空位和外生访问顺序，在相同阈值下比较。啤酒零售商的 40 周预提交行动和公共品 P1 的 10 轮预提交行动均从开局确定性重演，保留原回放。
- **E 验证。** 逐课验证合法处理进入真实模型、同配置哈希稳定、导出和经济时钟原事件可核对。对精确拍卖回放核对原哈希，对非法参数、错用认证费、不同学生行动拒绝配对。Chrome 实走初态比较、两种行动序列和 5 组种子导出。 [契约](../../../tests/contracts/test_parameter_lab.py) · [浏览器](../../../tests/e2e/test_parameter_lab_browser.py)

本轮的规则实验保留现有预设。改参数或行动方案会创建新运行。已有引擎的旧配置与运行内容仍能读取。运行中交互式暂停和状态分叉、带自定义参数的 Live 属于后续能力。五种子结果是本地仿真样本。
