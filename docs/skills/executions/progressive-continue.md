# 渐进课堂续学与证据回查

本分支基于公开仓库的 `2c4a7d1`，沿用已有学生端、案例与依赖修复。[运行方式](../../../frontend/README.md)

- 首页恢复当前浏览器上次课堂的阶段、原选择、回放位置和已揭示范围。原运行由相同规则输入重建并核对编号。
- 实验笔记直接打开解释、基线原事件与政策组原事件。既有 v1 四阶课堂解释和原实验室入口仍可读取。
- 双向拍卖在窄屏自动暂停时，订单证据与后续操作一同进入视口。供需无交叠实验有独立进度。

Chromium 和 WebKit 测试使用同一持久档案模拟前一天关闭浏览器与次日重开。学生对 96 代币限价预测不成交，在第三阶事件 4 暂停。次日从首页续学，原预测和事件 4 保持，事件 5 尚未揭示。完成政策比较并保存后，回到实验笔记查回两侧原事件。基线在簿单 O001 定价 96，原事件前后成交量分别为 0 和 1。新课堂通过同源静态资源完成该流程。旧课堂入口另与本工作树的原学生端复跑。[浏览器测试](../../../frontend/tests/continue_browser.py)

发布范围包括渐进课堂源码、可再生的固定种子初始输入、测试和文档，以及首页模型设置入口依赖的本地实现。浏览器储存、运行数据库、本地录屏、截图和构建目录留在本机。

## 执行与验证

- 复用既有课堂状态机、政策比较和原实验室入口。测试校验读取旧解释、拒绝不一致的运行身份及保留揭示范围。
- 使用 Playwright 在独立发布工作树复测续学、原事件回查和十二课入口。Chromium 与 WebKit 分别覆盖桌面和窄屏。
- 从锁定清单构建新旧前端。运行前端契约测试和两种内核的逐帧对照，核对 64 条运行路径、4,640 帧。
- 模型设置由本地同源服务提供。29 项接口与实验回归覆盖八种供应商配置、凭据不回传及旧版模型实验，供应商传输由测试替身处理。
