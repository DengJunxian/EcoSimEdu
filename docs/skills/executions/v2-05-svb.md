# V2-05 · 实际技能与产出

- **pm-execution:test-scenarios** 用空白学生档案定义起点，逐步检查可见结果、暂停时的两个方向回链、政策重新预测、首次与重复作答、备份和恢复。案例、条件、断言及隔离浏览器脚本见 [V2-05 验收](../../v2/executions/V2-05.md) 和 [可执行场景](../../../frontend/tests/svb_flagship_browser.py)。
- **Playwright** 通过 CLI 在实际运行的本地生产页定位史料链接，使用项目已经配置的 Playwright 浏览器实跑课堂、原事件、迁移和归档。在 390px 检查 Chrome 与 WebKit，在 1440px 检查 Chrome，并加测 320px WebKit。
- **Impeccable** 读取项目界面上下文与响应式规范，复用 V2 工作台现有卡片、焦点样式和表格。检查真实桌面和窄屏截图，解决配对表窄屏数字断行，并复核讨论所需的单位与原事件入口。
- **Analyze Data Quality** 为初始网络与两组结果核对粒度、时点与资金单位。用独立 Python 引擎验证账表、申请、实付和 60 名储户实际收到的邻居消息。将固定种子开局加到 [来源与数据校验](../../../cases/data-assets.json)。史料使用原发布方网页和已有来源登记，课堂不含外部原始银行流水。
