# ED07 · 导师与故障降级

diagnosing-bugs 用错单位、未来事件、错题版本、错草稿和非法模型选择构造可观察失败。用已有预算、幂等及超时注入通道复测。

本地从发布题判据定位误项，按已提交字段给结构反馈。在线可选择已核对追问，不发送原草稿给供应商。坏选择与超时回退。本轮无真实供应商回执。
