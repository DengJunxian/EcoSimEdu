**A · 发现**　核对实际宿主清单、项目 AGENTS.md、升级包 UP02、三旗舰规格、教学审查及合同草案。拍卖运行的控制来源为 `auction.py` 与 `cases/double_auction/model.md`。`cases/*/case.json` 保留案例身份、旧阶段、来源与内容。

**B · 选择**　读取并使用本机 `data-analytics:analyze-data-quality` 1.2.0 的粒度、缺失、主键和引用检查，以及适用的共享来源选择和分析质量说明。教学编排采用目标—操作—反馈—证据映射，参考 PhET 的先预测再检验与开放解释活动。来源核对覆盖 Smith 原论文出版信息，Nobel 自述链接本次返回 403，保留现有来源登记。 [PhET 活动设计指南](https://phet.colorado.edu/files/guides/PhetGuideActivityDoc_v8-final_en.pdf) [Smith 原论文出版页](https://www.journals.uchicago.edu/doi/10.1086/258609)

**C · 执行**　`cases/double_auction/lesson-v2.json` 提供七个可渲染场景、八项指定误区及入场练习，另含带不确定分支的 B01 成交预测。教学练习用独立示例，运行证据由事件选择器绑定。比较阶段分别说明固定报价下的需求变化与双边费用。解释阶段才介绍全市场边际估值，笔记以复算、追踪与适用条件作自评。两份 `lesson-v2.draft.json` 包含 SVB 和 Schelling 的七场景初稿，当前 API 继续返回它们的兼容阶段。

**D · 交接**　内容与校验由本包维护，已将字段、B01 预测 ID、选择器及回放测试点交接给首课渲染和笔记实现。发布入口用 `load_lesson_scenes`，兼容调用原来的 `load_case` 与运行合同。原阶段 ID 保留。内容版本 `2.0.0` 与引擎 `double-auction/1` 独立。静态校验检查场景顺序、来源、观测量、事件及字段、静态角色、反馈分支与缺失提示。运行核对负责当前游标与引用对应关系。

**E · 验证**　`.venv/bin/python -m services.simulation.lesson_scenes` 通过 12 课及两份草稿。`.venv/bin/python -m pytest -q tests/contracts/test_lesson_scenes.py` 通过 12 项，覆盖生产 API 的新版与兼容场景响应。按种子 1962 检查基准报价 96 与 1、需求报价 96、收费报价 96、103 与 108，共 889 个事件、27 笔成交。事件序号唯一且分别对应快照；每笔均可回查真实双订单和先在簿订单，成交价等于此订单报价。按成交前已成交数量取双方当时边际值，现金和商品差额、买卖剩余与平台费用均可复算。报价 1 的 B01 入簿但到收盘未成交，市场有 4 笔他人成交。收费下报价 103 或 108 的 B01 被规则拒绝，市场仍有其他成交。
