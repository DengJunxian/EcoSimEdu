# UP05 · 银行账本与储户网络

## A · 发现

读取实际的 UP05 提示、SVB 课堂规格、三组原有情景与银行引擎。核对到账、待付、分角色状态及网络由哪个模型字段提供。试题、账表和图的数值由课内模型生成。史料一栏复核关闭与存款人处置的日期和表述。 [美联储复盘](https://www.federalreserve.gov/publications/2023-April-SVB-Executive-Summary.htm) · [联合声明](https://www.federalreserve.gov/newsevents/pressreleases/monetary20230312b.htm)

## B · 选择

采用本机 data-analytics:analyze-data-quality 1.2.0 核对事件粒度、请求键、账表等式与未来泄露。沿用 Impeccable 4.8.0 的 Operate 方法和现有纸白深绿主题，采用深绿银行节点、点线申请、虚线消息和实线到账，用角色选择与事件列表提供等价操作。课堂文案按两份 anti-defensive-writing 指南保留机制范围、缺事件和相同结果。真实操作通过 Python Playwright 与本机 Chrome 复走。

## C · 实作

- D01 开局信息由原储户和关系网初始化生成，提供本次工资款、存款、保障额度及观察对象。工作台按当前时间显示消息、请求、实付与账户快照。按请求编号回查每笔付款，按消息来源键打开源申请。
- 研读阶段用谓词寻找「轮末待付大于零且净资产为正」。学生分类并计算当前帧权益，按实际待付行核对原申请与已付。账本计算和运行引用可随笔记导出。
- 发布七个场景及八类误区反馈。两组对照沿用原种子、工资时点和初始权益，按共同轮末查看同一储户。比较现金缓冲时说明证券敞口随资产构成同时变化。 [场景内容](../../../cases/svb_run/lesson-v2.json) · [领域投影](../../../services/simulation/svb_view.py) · [学生界面](../../../student-web/src/cases/svb/svb-panel.tsx)

## D · 交接

领域模块提供开局 briefing、当前时点指标、网络和动态暂停位置。共享课堂负责场景、游标、配对、引用及导出。原规则模型、SVB 保存运行与通用旧链接继续使用既有身份。

## E · 核对

基准种子 20230309、第一轮提交时，序号 3 的申请增加 32 待付，现金和存款负债不变。序号 4 实付 32，两项各减少 32。序号 5 的消息行按原始索引连到真实的先前申请。第 2 轮结算后序号 9 的现金为 0，轮末待付为 107，权益为 155，其中 D16 申请 42、已付 4。缓冲组开盘现金 500、权益 400，首次符合谓词的点为第 3 轮。另用原模型的测试情景将开盘证券全额换为现金，全部 1441 单位申请付清，动态定位正常到达收盘。 [机制回归](../../../tests/mechanisms/test_svb_lesson.py) · [投影契约](../../../tests/contracts/test_svb_classroom.py) · [浏览器回归](../../../tests/e2e/test_svb_flagship_domain.py)
