# UP01｜首页、导航与设计系统

| 步骤 | 实际动作 |
| --- | --- |
| A 发现 | 以当前工作树记录为准，核对 AGENTS.md、PRODUCT.md、原版页面和技能入口。确认本机 Impeccable 4.8.0、Playwright CLI 包装脚本和 Chrome 可用。 |
| B 选择 | 阅读 Impeccable 主说明、new-work 与 craft-floor。使用该方法确定首屏任务、阅读层级和窄屏组合。读取 Playwright 主说明与 CLI 参考，用同一生产构建做浏览器操作。 |
| C 执行 | 运行 `impeccable context --target student-web/src/main.tsx`，对照给定设计板和原版截图，沿用项目纸白与深绿。卡片接入真实课程名称、开局行动、来源身份与时长；续学和笔记接入本机实际草稿。 |
| D 交接 | 页面与入口由 UP01 维护；根代理提供 FastAPI 的受限页面路径及新版拍卖的 Scene、笔记和存储读取。原版课程、运行和新旧记录同时纳入导航验证。 |
| E 验证 | 生产构建通过。新导航回归 5 项通过，覆盖 320/390/768/1440 像素、键盘、筛选、生产刷新、浏览历史、真实笔记导出、旧运行以及无效参数和 404。机械检查返回空数组。独立评审定位的第 0 阶段标签和筛选框边界对比度两项问题均已修复并复查。 |

Impeccable 使用方案已给定的构图方向，按有视觉先例的新页面展开。用户已授权在既定范围内自主推进，执行采用暖纸底、深绿和线状机制图的代码实现。技能运行与页面截图均来自本机本轮。

- 页面与样式在 [app](../../../student-web/src/app/)，入口在 [main.tsx](../../../student-web/src/main.tsx)，生产路由在 [api.py](../../../services/simulation/api.py)。
- 使用本机 Chrome 和独立 SQLite 运行 `npm --prefix student-web run build` 及 `.venv/bin/python -m pytest -q tests/e2e/test_upgrade_navigation.py`。
- Playwright CLI 打开生产页面，截取各宽度首页，以及选中筛选框、案例导入、续学与笔记状态，截图位于本机 `output/playwright/up01-*.png`。原版是拍卖课入口和工具标签，新版首屏先说明平台用途并直接提供新版首课与课程路径。
- 原版课程、运行与高级实验通路的 48 项回归首跑 47 项通过。全局模型实验页添加返回选中课程的链接后，模型实验的两项回归重跑通过。
- 首次独立完成经济操作的 90 秒目标仍需学生实测。
