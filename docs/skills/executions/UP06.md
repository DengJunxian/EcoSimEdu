# UP06 Schelling 社区课堂

- **A · 发现**。检查项目 AGENTS、UP06 冻结案例、现有社区地图的方向键与行列选格、模型输出的完整 grid 和稀疏 entities。沿用现有理论来源登记，保留 20×20、各 170 户和 60 处空位。
- **B · 选择**。采用 Impeccable 4.8.0 的 Operate 和 craft floor 检查层级、窄屏与焦点。实际读取 Playwright 本机说明与浏览器工作流。课程内容按两份 anti-defensive-writing 的范围和证据一致原则编排，保留无自动搬迁、缺值、非全员达标的终止分支。复用模型与独立邻域计算核对。
- **C · 执行**。九格规则练习允许逐格选分母，再分别重算 30% 和 50% 的判定。开局地图展示 A001 和预留空位的实际邻居，运行仍使用原有两种行动。迁居视图按原址、新址和受影响居民连接真实事件，固定居民从每帧完整地图重新定位；同时展示满意率和同类邻接率及各自分母。课程包含八项概念反馈与一次实际自动迁居预测，导出、配对与保存走共享课堂。 [场景版本](../../../cases/schelling_segregation/lesson-v2.json) [地图与邻域](../../../student-web/src/cases/schelling/schelling-panel.tsx)
- **D · 交接**。内容和地图交给共享课堂；既有地图坐标选择、箭头和读屏提示仍可用。共用播放器提供当前帧、前一帧和真实同步轮次；本课只计算当前地图的邻居并标示同一轮的时间位置。混合、已分化初态对照交 UP08。
- **E · 验证**。模型组 6 项和 390、1440 px 的 Chrome 领域回归 2 项通过。逐迁居使用独立计算复核受影响居民、前后邻居和人口类型、空置守恒。小棋盘覆盖孤立、边界和目标格排除原始位置。引擎模型的无空位阻塞与一轮上限样本分开验证。Impeccable 机械检测返回空数组。Chrome 实跑 390 和 1440 像素两组通过：预测、方向键及行列选格、A001 真实迁居、受影响居民引用、隔 20 多个事件跳到空 entities 的轮末、焦点复位与无外网请求。实拍查看了九格侧栏、受影响标记和表格窄屏回流。 [机制复核](../../../tests/mechanisms/test_schelling_lesson.py) [浏览器回归](../../../tests/e2e/test_schelling_flagship.py)

种子 1971、学生搬到预留空位的结果为 0% 时 1 次搬迁、50.14% 邻接率，30% 时 112 次、84.55%，50% 时 155 次、92.71%。三个情景均实际达到全员阈值。0% 的一次搬迁来自学生开局操作。
