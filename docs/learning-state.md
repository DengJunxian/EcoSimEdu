# 学习状态和恢复

`student-web/src/study.ts` 以 case_id 与版本隔离浏览器记录。stage 是当前页面，unlocked 是可访问的上限。预测选项含不确定，解释题回答后展示离线反馈，正确性不作为通行条件。完成条件为三组已完成运行、两条不同的成交证据和观察、机制、条件、迁移四项笔记。重新提交基准会使旧分支和引用退出当前草稿。

执行状态由 SQLite 保存。播放游标和角色选择由 run_id 隔离，页面刷新恢复游标、角色与草稿，播放恢复为暂停。导出的学习笔记包含预测、实验分支、run_id 与事件 seq，导入会重新向现有本地服务验证这些引用。运行导出可独立阅读。学习记录复原适用于保有原运行数据库的环境。跨库迁移运行的导入协议待开发。案例版本不匹配时提示重新确认，保留浏览器中的旧项。

契约与两组边界见 `schemas/double_auction.run.schema.json`、`tests/contracts` 和 `tests/e2e`。
