# 首课界面

实验读本首页以问题和供需示意引入，浅暖底与深绿图面区分读本和实验图。进入课程后，步骤导航与单列任务工作区处理推进、回看和主体证据。中文宋体仅用于首页标题，正文用本地 CJK 字体，图表配实线/虚线和文字标签。表单与交互采用可见焦点、主要按钮 44 px、紧邻操作的校验信息；无运行时字体/CDN。

样式令牌和断点见 `student-web/src/style.css`。首课使用原生按钮、radio、select、range、details 和表格。成交点可键盘定位，成交关系有文本列表，证据提供原始订单。窄屏导航折行，数据表在独立容器滚动。

## V2 共用界面

两套学生前端读取同一份[界面令牌](../../content/student-theme.css)，包括暖纸底、正文墨色、深绿画布、链接颜色、表单边界、焦点、警示、间距与 44px 控件。问题标题使用本机宋体字族，课堂标签、按钮和数据使用正文无衬线字族。字体与图表均由本地页面提供。

[共用组件](../../content/student-ui.tsx)提供站点壳、主导航、页标题、当前位置、案例卡、进度导航、当前任务、主体透视及证据面板。案例卡先展示学生要回答的问题，课程名仍是可辨认的索引。四阶首页保留四条路径和十二门课，案例库和详情复用原目录与课程资料。

| 课堂宽度 | 观察视图 |
| --- | --- |
| 320–767px | 「经济世界」「主体」「系统结果」分屏。回放与证据共用同一个运行位置。 |
| 768–1159px | 经济世界和系统结果在左侧，主体与关系在右侧。 |
| 1160px 起 | 三个观察区并列，证据工作区位于其下。 |

颜色和形状共同表示主体状态。节点选择还有轮廓及同名的原生选择控件，纳入某事件的贡献主体用虚线轮廓标示。金融图保留红涨绿跌与带符号数值。听觉与键盘等价操作包括原事件链接、表格定位及明确的当前步骤。
