# 首课交互状态

- 首页提供开始、继续、来源和笔记导入。实验开始前显示私人价值与购入边界。
- 规则执行要求合法报价，固定预设显示明确报价。有故障时保留现有草稿并允许重新创建。
- 复用一个运行的游标和角色选择联动成交点、成交双方、挂单与账户。首笔成交触发教学停顿，之后可继续、逐步、调整倍速或跳转。
- 预设、在线不可用、零成交、缺失和取消各有独立文本。比较表在结果未就绪时显示待运行。
- 七步独立于执行状态。用户可以回看已解锁步骤。页面刷新恢复证据和角色，错误预测仍可继续。后台保存的运行与学习笔记分别导出。

## V2 四阶课堂

- 阶段二开放经济世界与主体，阶段三开放系统结果。点击个体和键盘激活个体调用同一选择。窄屏切到主体页并把焦点给个体名单。标签支持方向键、Home 和 End。
- 主体关系、微观状态、宏观指标和证据使用同一个游标。图旁的「按表格查原事件」打开有焦点的数值表。表格和曲线都遵守课堂已揭示范围。未出现成交时价格显示「未定义」，缺少指标记录有单独文本。
- 成交暂停后，把结算价依据和下一步放在订单明细之前。手机滚动并聚焦到证据。回查两张订单后，可回到原成交并往下观察引用该价格的报价。
- 课堂加载、无法打开或计算、无法恢复进度、无匹配案例、在线模型不可用都有学生能执行的后续操作。无法恢复的检查点在当前练习期间保留，学生可显式开始新练习。进入网络离线状态时，已打开的浏览器规则实验可以继续运行。
- 系统的减少动态效果设置关闭主体着色与搬迁过渡。时间轴只在学生触发播放后推进，关键事件仍触发暂停。
