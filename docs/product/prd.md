# 第一条学习路径

主要用户是自学经济学的学生。学习版面服务三种任务：初学者按步骤实验，已有微观经济学背景的学生核查反事实，教师投屏演示并导出记录。此处为设计目标。

| 需求 | 学生任务 | 验收 |
|---|---|---|
| M1-01 | 从首页进入案例并读到私人价值 | 开始、预测并提交一笔报价后即可进入结果 |
| M1-02 | 从成交价定位成交双方和订单 | 同运行、同事件的成交价、买卖方与订单 ID |
| M1-03 | 对照需求变化与交易费 | 同种子、同学生报价，显示干预和原始指标 |
| M1-04 | 写出证据、条件和迁移 | 预测正确与否均可完成，刷新恢复，笔记可导出与校验导入 |
| M1-05 | 基础模式本地运行 | 外部网络阻断后完成学习 |
