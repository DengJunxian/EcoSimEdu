# 教学交互借鉴

CORE Econ Doing Economics 的分步项目为「先操作、再解释」提供参考。NetLogo Schelling 示例展示参数改变后观察涌现结果的交互。PhET 的教学资料用于设计先预测、再观察、最后解释的任务链。参考范围聚焦交互设计，本地学习效果尚未测量。

- [CORE Econ · Doing Economics](https://www.core-econ.org/project/doing-economics/)
- [NetLogo · Segregation](https://ccl.northwestern.edu/netlogo/models/Segregation)
- [PhET · Teaching Resources](https://phet.colorado.edu/en/teaching-resources)
